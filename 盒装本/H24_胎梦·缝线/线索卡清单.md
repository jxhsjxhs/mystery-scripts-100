# 《胎梦·缝线》· 线索卡清单（DM / 印制用）

> 共 5 张线索卡，另有《线索卡.png》组图可直接裁切印刷。
> 建议做成 63×88mm 卡片，正面编号 + 物证描述，背面留白。

## 线索卡内容
1. 备产新婴衣针脚只到第六根，窦嫂藏的旧婴衣多第七根、线色偏深。
2. 第七根线打的是双回针，与芮妈顶针盒里余线、针法一致。
3. 产房簿三年前一页「七」字被朱笔圈过，圈墨与涂生袖中朱笔同色。
4. 摇篮绳结有新拧痕，所谓「自己晃」是有人牵绳，非梦兆。
5. 该页产房簿「抱出／抱入」两栏名字被纸片补过、补纸压在旧印上。

## 印制建议
- 每条线索单独制卡；编号与《线索卡.png》一一对应。
- 物证类可配实物道具（纸张、票据、照片、器物）提升沉浸。
- 线索须能被搜到、可被回看验证；DM 不要提前放完，按幕逐步解锁。

# 《帘后三爷有两个人》· 线索卡清单（DM / 印制用）

> 共 5 张线索卡，另有《线索卡.png》组图可直接裁切印刷。
> 建议做成 63×88mm 卡片，正面编号 + 物证描述，背面留白。

## 线索卡内容
1. 窦先生的暗账里，单数页收货人写「左卓」、双数页写「右卓」，两栏字迹一硬一软——从第一页起就记着「三爷是两个人」。
2. 帘后那副面具内衬有两道深浅不同的勒痕、两圈不同尺寸的汗渍，显系两副头围轮流戴过。
3. 花厅伙计证词「戌时三爷咳了三声、左手递茶」，而内室尸体旁收货单是「右手握笔、案上点苏合香」；同一时刻两种惯用手与熏香，只能是两个人在场。
4. 排班表十六原写「苏」，被人用同色墨描成「陆」，透光压痕仍是「苏」字；改笔用的正是苏晚账桌上的松烟墨。
5. 勒死窦先生的琴弦上沾着苏合香与松烟墨，二者都只出现在苏晚当值时的帘后。

# 《相亲角，我妈和我是同一个人》· 主持人手册（DM 专用 · 玩家勿看）

## 〇、商业化包装（宣传 / 开本导语，无剧透）
- 一句话卖点：一张优质男嘉宾资料卡，一上午被四位家长认领，打卡钟却只吐出「到场一人」。
- 上架分类：沙雕·相亲角一人四认 / 4 人 / 进阶 / 60–90 分钟

### 盒背文案
城南公园相亲角，同一张「优质男嘉宾」资料卡一上午被四位家长同时认领：照片是同一人，署名却写成「本人」「本人母亲」「本人小姨」「本人本人」四款，爱好栏涂成「爱静」「爱闹」「爱静闹结合」「爱被安排」。凉亭老式打卡钟每逢整点「咔」地吐出小票：「本时段到场人数：1，登记人次：4」。红娘摊主一拍桌：不把「到底来了几位、谁才是真身」盘明白，谁都别摘胸花。四位「家长」面面相觑，谁也不肯先挪步。

### 卖点
1. 四人刚好坐满一桌，九十分钟一局，进阶玩家也能轻装上阵。
2. 相亲角一人四认、胸花折扇齐飞，社恐看了都替他们捏把汗地笑。
3. 以「身份辨认」轮流认卡盖章，只比谁说得圆，不烧脑不冷场。

### 开场导语（DM 宣读）
你们四位今晚都站在了相亲角的凉亭里：同一张资料卡被认了四回，打卡钟只肯吐出一个人次，摊主的胸花还攥在手里没发。谁是本尊、谁陪谁来的，先别忙着替彼此拍板——今晚要闹清楚的，是这卡上到底登了几位、这胸花该别到谁身上。喇叭就搁桌上，话筒交给你们。

### 角色预告
- 群主·孟美琪：相亲角信息群群主，手持喇叭的统筹担当；看上去非要把登记秩序一寸寸捋直。
- 社恐·温吞水：被安排来相亲的本人，全程想把自己缩进折扇；看上去只当是陪小姨来逛逛。
- 戏精·佟排场：自称「小姨」，戏服胸花全套；看上去嫌资料卡太素、当场就要加才艺栏。
- 显眼包·贾大方：自称「本人母亲」，拎着最大号保温壶；看上去逢人便夸自家条件好、卡是亲手填的。

## 二、发本顺序
1. 先让玩家抽/选角色，按下列顺序发《角色剧本》与《角色卡》（每人只拿自己那份）：
   - 群主·孟美琪
   - 社恐·温吞水
   - 戏精·佟排场
   - 显眼包·贾大方
2. 确认每人都读完且没拿错本，再宣读「全场公开背景」。
3. 线索卡按「建议揭示时机」分幕投放，勿一次性摊开。

## 三、三幕流程详述
- **第一幕**：红娘摊主锁摊，DM 发四卡四章，第一次「整点咯」集体抢钟，数清「到场 1 / 登记 4」，四人各用一句话圆自己的署名，互相听出「怎么都像在念别人写的词」。
- **第二幕**：开放「透光叠卡」「打卡钟存根」「折扇擦痕」「才艺赛报名表」四处搜证，抢章不停，拼出「群主凑 KPI / 本人改人设 / 小姨是蹭戏 / 母亲占 C 位」四条动机，并发现报名表早于认领。
- **第三幕**：红娘宣布「最终核验」——四人须合演一段「一上午到底发生了什么」的定格小品，每人只能说一句台词，且四句合起来必须让打卡钟吐出「到场人数：1 / 登记人次：1」才算过户成功。

> 每幕开始：简述本幕目标 → 开放搜证 → 组织一轮轮流发言 → 收束到本幕矛盾点。
> 第三幕末组织投票/指认，再念读《结局卡》。

## 四、线索发放表
1. 四张资料卡对着台灯透光叠看，照片、生日、身高、甚至「左耳有小痣」全部重合，只有署名栏与爱好栏是四套不同笔迹后补的——物理证明是同一张底卡复印改字，不是四个人。
2. 打卡钟整点小票存根连号 09:00 至 11:00，每张都印「到场人数：1」，但「登记人次」从 1 逐张涨到 4，且涨的那几张边缘沾着同一支红色记号笔的墨——与群主喇叭上挂的 KPI 统计笔同色。
3. 资料卡「爱静闹结合 / 爱被安排」两行用的是极细的浅灰铅笔、字被反复擦过三遍，擦痕缝里检出折扇柄上的竹粉——指向全程缩在折扇后的社恐本人半夜改卡。
4. 凉亭座椅扶手上贴着「家长才艺赛报名表（润嗓组）」，报名人签「贾大方」，交表时间戳比「本人母亲」第一次认领卡还早二十分钟；背面还印着广场舞队「台词练习第 7 页：护侄」字样。

## 五、反转与高潮
铺垫：全程把「本人」当成没到场的可怜孩子，DM 反复问「真身今天到底来没来」，社恐每次都把折扇往脸前一挡。反转一：折扇竹粉 + 浅灰铅笔擦痕锁定——「爱静闹结合 / 爱被安排」正是本人自己写的，他不是没到场，他是既来了又拼命假装没来，把「到场 1」硬演成了「登记 4」里最安静的那一个；他改卡不是捣乱，是怕被安排开口，于是提前替自己把「不用说话的人设」写进系统。反转二：群主凑 KPI、小姨蹭戏、母亲占座看似各怀鬼胎，其实三人今早都在凉亭撞见过这个缩在折扇后的年轻人，谁也没忍心点破「你就是卡上那位」，才不约而同替他多认领了一个身份，好让他能继续躲着——四张卡是一场合谋的、笨拙的体贴。

## 六、完整真相（含全部角色秘密 · 仅 DM）
各角色秘密与任务：
- **群主·孟美琪**：秘密＝四种署名是她为了冲「本群今日活跃家长数」KPI，拿同一张底卡复印改字凑出来的，真身只来了一位她没好意思说；任务＝把 KPI 圆成「确实来了四位优质家长」，保住群活跃榜第一。
- **社恐·温吞水**：秘密＝卡上「爱静闹结合」和「爱被安排」两句是他自己半夜偷偷改的——他既怕冷场又怕被安排，干脆把两种人设都写上，赌红娘自动匹配最省话的那个；任务＝不被认出是本人、不发言、不被安排第二场，最好原地蒸发。
- **戏精·佟排场**：秘密＝她根本不是小姨，是隔壁广场舞队来蹭相亲角免费矿泉水兼练「家长威仪」台词的，认领纯属入戏；任务＝把这场演成一出完整的「护侄大戏」并收获掌声，顺便续杯矿泉水。
- **显眼包·贾大方**：秘密＝保温壶里装的根本不是给儿子的汤，是她自己报名「相亲角家长才艺赛」要用的润嗓胖大海，填卡只是为了占个靠凉亭的遮阳座；任务＝抢到凉亭 C 位坐满全场、顺路把才艺赛报名表交了。

真相与证据链：
真相：社恐温吞水被家里安排来相亲，到场后怂到不敢承认真身，半夜偷偷把资料卡爱好改成「爱静闹结合 / 爱被安排」，指望系统替他选最省话的结局；群主孟美琪为冲群活跃 KPI 拿这张底卡复印出四款署名；戏精佟排场是广场舞队来蹭水练「护侄」台词的，顺势认领小姨；显眼包贾大方填「母亲」只为占凉亭遮阳座交才艺赛报名表。今早三人都瞧见了折扇后发抖的本人，默契地没戳破，一人多认一个身份替他打掩护，于是「到场 1、登记 4」。打卡钟从头到尾没坏，它只是诚实得有点残忍。主结局（四句定格）：四人各念一句——「来了一位」「他不太想说话」「那我们就都替他报个名」「钟，麻烦写 1 和 1」，打卡钟「咔」地吐出「到场人数：1 / 登记人次：1」，红娘把四张卡订成一本小册子题名《今天没人被安排》，社恐终于从折扇后露出半张脸说了全场唯一一句多余的话：「……谢谢，水能续一杯吗」。分支：若定格里有人非要点名「真身是谁」，则 DM 让打卡钟连吐四张「登记人次：4」把小品卡成循环，四人被迫一直替他圆下去，笑到红娘自己把摊收了。

## 八、节奏与安全提示
- 防冷场：第一次「整点咯」先由 DM 自己冲去按钟、捏着嗓子圆一句「我这一款是……本人本人」，把「抢着拆自己台」的调子定下来，再让四人上。
- 发梗时机：每当两人盖同色章，就把四张卡叠起来对光慢念「本人 / 本人母亲 / 本人小姨 / 本人本人」，念到「本人本人」刻意顿一拍；这句回收到第三幕定格时再念一遍，变成收尾暗号。
- 揭「合谋的体贴」别太早，先让四人互相拆台到有人脱口「你根本不是小姨吧」，等彼此都露了馅、气氛最热闹时，再翻折扇竹粉那条线，让笑突然静半秒——哈哈镜的刀只割这一下，不真疼。

# 《封印·井泥》· 线索卡清单（DM / 印制用）

> 共 5 张线索卡，另有《线索卡.png》组图可直接裁切印刷。
> 建议做成 63×88mm 卡片，正面编号 + 物证描述，背面留白。

## 线索卡内容
1. 井栏最外一道红布断口平齐、纤维是利器割断，非风雨磨断的毛边。
2. 木匣朱砂符大半被井泥糊住，刮开见符文完整、根本未「破」。
3. 阿岩族谱夹的残页：「某年以铜环为质，封争井之契于匣底」。
4. 章篓货担暗层一张外村字条，写明「取环来，换旧契一观」。
5. 铜环内壁刻着一个「质」字，与残页用词相合。

## 印制建议
- 每条线索单独制卡；编号与《线索卡.png》一一对应。
- 物证类可配实物道具（纸张、票据、照片、器物）提升沉浸。
- 线索须能被搜到、可被回看验证；DM 不要提前放完，按幕逐步解锁。

# 《业主群今晚不许发「收到」》· 角色剧本 —— 摸鱼·司徒躺

## 一、你是谁

## 二、全场公开背景（DM 开场宣读，所有人都知道）
「和风雅苑 3 栋业主群」立新规：今晚 20:00–21:00 为「静音实验」，发「收到」罚充十元公共电费。整点一到，群里「收到」刷了 99 条，系统标成「由 3 栋 502 转发」，可 502 业主坚称手机整晚扣在物业前台充电。物业把四位当事人请到活动室，桌上摆着旧路由器、群聊截图，以及一张涂改的《静音实验值日表》。不盘清「99 个收到谁发的」，谁也拿不回暂扣手机——包括那台被拉进群、昵称「3栋路由器」的设备。

## 三、你在人前的主张

## 七、分幕行动指引
- 第一幕：活动室落座，DM 念第一批截图、四人抢铃认领/甩锅，先把 99 条按「连发型 / 托管型 / 测速型」粗分三类，并发现全被标成「502 转发」。
- 第二幕：开放「充电线压痕」「旧平板缓存」「便利店小票与无线网络列表」「值日表涂改层」四处搜证，抢铃不停，拼出「保安压键 / 社恐托管 / 老板引网 / 群主空值日」四条线，并核对值日表「全体」实为无人。
- 第三幕：物业要求合交一份《静音实验异常说明》，四人须共用一张纸、每人只写一行，四行合起来必须同时解释「61 连发」「剩余 38 条」「路由器为啥在群里」且让电费账单归零。

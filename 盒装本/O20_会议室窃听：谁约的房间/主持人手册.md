# 《会议室窃听：谁约的房间》· 主持人手册（DM 专用 · 玩家勿看）

## 〇、商业化包装（宣传 / 开本导语，无剧透）
- 一句话卖点：三间会议室同段被约走，密谈第二天进了行业群，谁的房间谁担责，改一下预约全员都收到。
- 上架分类：职场博弈 / 3 人 / 进阶 / 90 分钟

### 盒背文案
公司三间会议室同一时段被约走，第二天，其中一间里的密谈内容出现在了行业群。行政贴出预约表：「谁的房间谁对内容负责」，于是三人各守一个房间名开始掰扯。改预约只要点一下，系统却会立刻给全员发一封变更通知。茶水间已经有人在低声谈「我替你认下来，你别声张」。行政上周领用的那批录音笔，编号连着，三间房各搁了一支。这间房，今晚该由谁来认？

### 卖点
1. 3 人 90 分钟进阶局，一张预约表，公司团建刚好开。
2. 改一下全员都收到通知，低声谈条件的话比表还薄。
3. 预约还原类玩法，房间名与变更通知都在，不预设谁认哪间。

### 开场导语（DM 宣读）
你们被叫来对着这张预约表时，三间会议室的名字都还挂在上面，改一下就会给全员弹一封变更通知。昨天的密谈内容已经飘到了行业群，行政把话贴得很明白：谁的房间谁对内容负责。你们各自的说法都摆在台面上，没人替谁确认。今晚要查清的只有一件事：这三间房里，该由谁把那个房间名认下来。

### 角色预告
- 预约·任行政：管预约系统、贴表、发变更通知的人，看上去只认「系统记谁就谁」。
- 封口·袁 P7：密谈发起人、最怕内容外泄，看上去急着把「谁约的谁担」钉死。
- 录音笔·柳秘书：被派来旁听记录的高层秘书，看上去只带耳朵、不多说一句。

## 一、基本信息
- 题材：职场博弈·会议室全录认领
- 人数：3 人（3 名角色）
- 时长：建议 90 分钟 ｜ 难度：进阶
- 核心机制：「房间认领 + 改约即广播」：三间房同一时段被约，按表「谁约谁负责」；可交易「我替你认、你别转发 / 我改预约人换封口费」，但预约系统每改一次自动给全员发一封变更通知——交易越密，通知越叠，等于把「谁在慌、谁跟谁谈过」群发给全层。取舍在于：

## 二、发本顺序
1. 先让玩家抽/选角色，按下列顺序发《角色剧本》与《角色卡》（每人只拿自己那份）：
   - 预约·任行政
   - 封口·袁 P7
   - 录音笔·柳秘书
2. 确认每人都读完且没拿错本，再宣读「全场公开背景」。
3. 线索卡按「建议揭示时机」分幕投放，勿一次性摊开。

## 三、三幕流程详述
- **第一幕**：三人各守一个房间名自陈「我那间谈了什么」，第一轮只开放预约表与领用单抬头；DM 把三支编号私下给录音笔·柳秘书。
- **第二幕**：开放「认房间 / 改预约 / 封口费」谈判，每改一次 DM 当场念一封全员变更通知；DM 依次放出领用用途栏、编号连号、外泄版本比对。
- **第三幕**：高层办催「责任说明」，三人须同时决定是否承认改约、是否亮录音笔编号；公布「全覆盖」事实与名单去向，结算谁被记进「怕担责」清单。

> 每幕开始：简述本幕目标 → 开放搜证 → 组织一轮轮流发言 → 收束到本幕矛盾点。
> 第三幕末组织投票/指认，再念读《结局卡》。

## 四、线索发放表
1. 行政领用单：上周领「录音笔 ×3」，用途栏手写「三间会议室全覆盖，不告知使用人」，审批人指向高层办。
2. 三支录音笔编号连号：与领用单一一对应，机身贴纸分别标 A / B / C 三间房，出厂批次同一箱。
3. 预约变更通知群发记录：共 4 封，收件人为全员，发送时间紧随三次「封口 / 改约」私聊之后，通知正文含「原预约人 → 新预约人」双字段。
4. 行业群外泄版本比对：与原话差一句，缺的正是封口·袁 P7 前一晚发给高层的「试探版」里删掉的那句，两版句序完全一致。

## 五、反转与高潮
第一重：三间房各一支同批录音笔、领用单写「全覆盖、不告知」——密谈本就被全录，「谁泄密」从开局是伪问题；外泄版还恰好是封口·袁 P7 自己删过一句的试探版。铺垫是领用用途栏与版本比对。第二重：改预约会自动群发全员通知，三次「封口 / 改约」换来四封广播；三人越想悄悄挪锅，越把「谁最慌」公示给了整层楼，而录音笔·柳秘书 要的正是这份名单。

## 六、完整真相（含全部角色秘密 · 仅 DM）
各角色秘密与任务：
- **预约·任行政**：秘密＝录音笔是他按「高管指示」三间房各放一支的，领用单上写着「全覆盖，不告知」，他早知道「谁泄密」根本不成立，却乐得看三人争；任务＝让三人至少改一次预约人，好把「有人试图篡改责任」写进说明交差。
- **封口·袁 P7**：秘密＝他其实自己把要点「漏」给过高层试探风向，外泄的版本比原话少了一句，正是他删过的那版；任务＝用封口费换另两人改预约 / 别声张，把房间责任挪到自己以外。
- **录音笔·柳秘书**：秘密＝行业群那版就是她按高层意思放出去的，目的是看谁会慌着改预约自保；三支笔的编号与领用单她手里有全套；任务＝收齐三人的改约通知 + 封口往来，攒一份「谁最怕担责」的名单回给高层。

真相与证据链：
高层按「组织韧性」名头让行政三间房全录、再由录音笔·柳秘书 放一版删过一句的内容进行业群，看谁会改预约自保；预约·任行政 乐得收改约通知交差。封口·袁 P7 本就自己漏过试探版，慌着拿封口费挪房间责任。结局（主）：四封变更通知收齐，「谁改过约、跟谁谈过」清清楚楚，录音笔·柳秘书 攒成《责任敏感度名单》回给高层；封口·袁 P7 排第一，预约·任行政 以「系统零篡改、如实记录」交差留任，三间房的录音笔原样收回箱里，编号一个没销。黑色幽默：全员收到第 4 封变更通知时，正文模板自动带了句「本次调整不影响会议内容保密性」，而附件正是那张领用单。分支：若三人第二幕谁都不改约、一齐亮出三支编号联署质疑「全覆盖」，名单缺「自保动作」、高层只能把放风记成「测试无效」收回；但「三人共同质疑录音」被标为协同对抗高层办，下一季这三间房的预约权一并收归行政直管。

## 八、节奏与安全提示
- 每改一次预约就当众念一封「原→新」全员通知，广播感是本局节奏；别私下改、别攒着念。
- 三支编号只给录音笔·柳秘书，明说「亮出来你那名单就攒不成了」；若她不出手，第三幕催说明时由领用用途栏「全覆盖」自然带出。
- 防过早破梗：领用单第一幕只露抬头、不露用途栏；「全覆盖」三字留到至少两封变更通知发出后再解封。

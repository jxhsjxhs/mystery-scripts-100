# 《枯井·绳上结》· 线索卡清单（DM / 印制用）

> 共 5 张线索卡，另有《线索卡.png》组图可直接裁切印刷。
> 建议做成 63×88mm 卡片，正面编号 + 物证描述，背面留白。

## 线索卡内容
1. 桶梁上七个死结，打法与篾叔绳匣里余绳的收头结完全一致。
2. 绳匣余绳比井台绳槽该配的长度短七圈，匣盖有新开合的指痕。
3. 桶里浑水只半桶、带井底红泥，桶沿一圈水痕未干，非今晨从河里挑来。
4. 禄嫂箱底一张二十年前的旧当票，写着「木匣一只，沉井为质」。
5. 井台石缝卡着半片朽木，木色与当票所记匣料相同。

## 印制建议
- 每条线索单独制卡；编号与《线索卡.png》一一对应。
- 物证类可配实物道具（纸张、票据、照片、器物）提升沉浸。
- 线索须能被搜到、可被回看验证；DM 不要提前放完，按幕逐步解锁。

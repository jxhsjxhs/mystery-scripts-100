# 《供应商回扣：三家一个老板》· 游戏说明书

## 开始前准备
- 指定 1 名主持人（DM），**提前通读《主持人手册》与全部角色剧本**。
- 按人数分发对应角色剧本与角色卡，每人只拿自己那份。
- 摆放线索卡（背面朝上）或按 DM 手册分幕投放；准备纸笔用于记录时间线。
- 关闭与剧情无关的外界信息，建议 建议 90 分钟 不中断。

## 游戏规则
1. **读本**：各自阅读角色剧本 5–8 分钟，记住你的身份、秘密与任务；不要念出秘密。
2. **开场**：轮流做自我介绍（可用剧本里的「建议开场自我介绍」）。
3. **搜证**：按 DM 指令进入搜证轮，每轮可获取/查看若干线索卡；可选择公开或暂扣。
4. **讨论**：基于线索互相质询、比对时间线、找出矛盾；可结盟也可欺骗。
5. **分幕推进**：共三幕，每幕 DM 会投放新信息并推进冲突（见 DM 手册）。
6. **投票 / 结局**：第三幕末按本局要求投票或指认；DM 据结果念读《结局卡》主结局或分支结局。

## 胜负与体验
- 本类剧本为**沉浸推理 + 角色扮演**，多数无硬性「输赢」，以「是否达成个人任务」+「是否还原真相」为体验核心。
- 完成本局任务、或投中真相/关键指认，即为本局高光；DM 可在复盘时点明各角色的暗线。

## 常见问题
- **Q：能把自己的秘密告诉别人吗？** 可以策略性透露，但一旦全盘托出会失去博弈空间，建议留到关键轮次。
- **Q：线索不够怎么办？** 回到角色剧本的「你要追查」与 DM 的节奏提示，重新比对已公开线索。
- **Q：有人提前猜到真相？** DM 按主持人手册「防过早破梗」提示引导，不确认、不否认。

- **追查**：与「让押中的那家过审，并把「换标底」的痕迹摊到另两位对接人身上。」相关的物证、他人证词里的矛盾、时间线缺口。

## ④ 主持人手册
# 《供应商回扣：三家一个老板》· 主持人手册（DM 专用 · 玩家勿看）

## 〇、商业化包装（宣传 / 开本导语，无剧透）
- 一句话卖点：三家同天递标、报价卡得整整齐齐，三张执照并排摆开、一个字都不差，今晚价低者算谁？
- 上架分类：职场博弈 / 3 人 / 硬核 / 90 分钟

### 盒背文案
年度采购比价，三家供应商同天递标，报价从高到低排得整整齐齐，刚好卡在预算上限内。比价室里三位对接人各守一叠标书，规则允许「答疑澄清」，走廊里于是有人低声换底价：「你告诉我他家底线，我这边让两个点」。茶歇时三张执照被顺手摆成一排——注册地址、联系电话、连开户行网点号，一个字都不差。这价低者得的一家，今晚到底怎么算？

### 卖点
1. 3 人 90 分钟硬核局，三叠标书一张比价桌，采购团建对味。
2. 报价排得比尺子还齐，走廊里的低声反倒比屋里响。
3. 标书比对类玩法，三份执照与答疑纪要都摊开，不预设谁家得标。

### 开场导语（DM 宣读）
你们守着各自那叠标书坐进比价室时，三家的报价已经从高到低排好，刚好压在预算线里。规则允许答疑澄清，走廊里已经有人低声谈底价了。茶歇时那三张执照并排一摆，谁都多看了一眼。你们各自的说法都摆在台面上，没人替谁确认。今晚要查清的只有一件事：这「价低者得」的一家，该认哪一叠。

### 角色预告
- 标底·苏采购：牵头比价、握着三家答疑纪要，看上去把「程序透明」念得最稳。
- 马甲·潘老板：三家供应商里最低价那家的对接人，看上去只图个长期合作。
- 回扣卡·葛财务：管付款与回扣卡入账，看上去只认合同、不多问一句。

### 上架标签
#3人本 #职场 #利益博弈 #硬核 #90分钟

## 一、基本信息
- 题材：职场博弈·三壳围标回扣
- 人数：3 人（3 名角色）
- 时长：建议 90 分钟 ｜ 难度：硬核
- 核心机制：「标底交换 + 同卡回扣」：每人代表一家对接，手里握着别家的报价底线，可私下换标底帮自己押的那家中选，中选后回扣按「帮过忙的人」比例分；但所有回扣走同一张卡，卡流水一拉就把换标底的先后串成一条线。取舍在于：换底价 = 押中率更高，可换得越勤

## 二、发本顺序
1. 先让玩家抽/选角色，按下列顺序发《角色剧本》与《角色卡》（每人只拿自己那份）：
   - 标底·苏采购
   - 马甲·潘老板
   - 回扣卡·葛财务

## 三、三幕流程详述
- **第一幕**：三人各自「报个价、说说优势」，第一轮只开放三叠标书与营业执照复印件；DM 把回扣卡流水私下给回扣卡·葛财务。
- **第二幕**：开放「答疑 / 换标底 / 分点」谈判，每换一次当众在比价板记「谁向谁透了哪家的底」；DM 依次放出纪要时间差、装订打孔、执照并排页。
- **第三幕**：定标唱价，三人须同时决定是否亮流水、是否承认三家同源；公布中选方、回扣真实来源与审计抽中情况，结算各人得失。

> 每幕开始：简述本幕目标 → 开放搜证 → 组织一轮轮流发言 → 收束到本幕矛盾点。

## 四、线索发放表

## 五、反转与高潮
第一重：三家供应商是同一老板的壳——执照三项全同、标书同机同纸、法定代表人签名同笔，「比价」从开局就是围标做高预算。铺垫是并排页与打孔偏移。第二重：所谓回扣不是供应商让利，是部门年终池先扣一圈再「返还」到同一张卡：三人抢着分的钱，本来就是从自己年终里切下来的；标底·苏采购 透底、马甲·潘老板 装憨、回扣卡·葛财务 装不知，全在替这笔循环账盖章。

## 六、完整真相（含全部角色秘密 · 仅 DM）
各角色秘密与任务：
- **标底·苏采购**：秘密＝他提前把另两家的报价底线透给了自己押的那家，约好中选后按点分回扣，回扣走的是同一张卡；任务＝让押中的那家过审，并把「换标底」的痕迹摊到另两位对接人身上。
- **马甲·潘老板**：秘密＝另外两家也是他的壳，围标做高预算是他和标底·苏采购 一起定的，回扣卡虽在苏手里，流水抬头却挂潘自己公司；任务＝把「三家」坐实成「三家独立」，别让执照并排被翻出来。
- **回扣卡·葛财务**：秘密＝她核对过，所谓回扣根本不是供应商让利，是从三人自己部门年终池里先扣出来再「返还」的，账做了一圈回到原处；任务＝用「不点破循环账」换自己那笔不被审计抽中，必要时把流水甩给另两人。

真相与证据链：
标底·苏采购 与马甲·潘老板 用三家壳围标做高预算，约定中选后按点分「回扣」；回扣卡·葛财务 早看出钱是从部门年终池先扣后返，却选择不点破换自保。结局（主）：「最低价」家如愿中选，比价板上一串「透底」记录被连号流水坐实，审计抽中时三人按「谁换过标底」依次被约谈；回扣卡·葛财务 因始终「只认流程」且未亮流水，单独摘清，那笔先扣后返的账原样留在池子里，三人的年终照少一圈。黑色幽默：定标通报写「经充分比价，节约预算 0%」，附的三家执照并排页被收进《供应商独立性证明》卷宗，谁也没撕。分支：若三人第二幕一齐亮流水、承认三家同源并废标，围标不成立、预算退回、年终池那圈扣款冲正；但「主动废标」被记成采购线重大异常，三人整条线下一年度全部改走集团集采，对接岗一并撤并。

## 八、节奏与安全提示
- 比价板「谁向谁透了哪家的底」当众写，第二幕末回看那一串，玩家自己会对上卡流水的时间。

## ⑥ 商业化包装（无剧透）
- 一句话卖点：三家同天递标、报价卡得整整齐齐，三张执照并排摆开、一个字都不差，今晚价低者算谁？
- 上架分类：职场博弈 / 3 人 / 硬核 / 90 分钟

### 盒背文案
年度采购比价，三家供应商同天递标，报价从高到低排得整整齐齐，刚好卡在预算上限内。比价室里三位对接人各守一叠标书，规则允许「答疑澄清」，走廊里于是有人低声换底价：「你告诉我他家底线，我这边让两个点」。茶歇时三张执照被顺手摆成一排——注册地址、联系电话、连开户行网点号，一个字都不差。这价低者得的一家，今晚到底怎么算？

### 卖点
1. 3 人 90 分钟硬核局，三叠标书一张比价桌，采购团建对味。
2. 报价排得比尺子还齐，走廊里的低声反倒比屋里响。
3. 标书比对类玩法，三份执照与答疑纪要都摊开，不预设谁家得标。

### 开场导语（DM 宣读）
你们守着各自那叠标书坐进比价室时，三家的报价已经从高到低排好，刚好压在预算线里。规则允许答疑澄清，走廊里已经有人低声谈底价了。茶歇时那三张执照并排一摆，谁都多看了一眼。你们各自的说法都摆在台面上，没人替谁确认。今晚要查清的只有一件事：这「价低者得」的一家，该认哪一叠。

# 《供应商回扣：三家一个老板》· 盒面文案 / 宣传物料

> 可直接用于电商详情页、盒背、海报、店铺介绍；**严禁剧透**（不写真相/反转/凶手）。

- 一句话卖点：三家同天递标、报价卡得整整齐齐，三张执照并排摆开、一个字都不差，今晚价低者算谁？
- 上架分类：职场博弈 / 3 人 / 硬核 / 90 分钟

### 盒背文案
年度采购比价，三家供应商同天递标，报价从高到低排得整整齐齐，刚好卡在预算上限内。比价室里三位对接人各守一叠标书，规则允许「答疑澄清」，走廊里于是有人低声换底价：「你告诉我他家底线，我这边让两个点」。茶歇时三张执照被顺手摆成一排——注册地址、联系电话、连开户行网点号，一个字都不差。这价低者得的一家，今晚到底怎么算？

### 卖点
1. 3 人 90 分钟硬核局，三叠标书一张比价桌，采购团建对味。
2. 报价排得比尺子还齐，走廊里的低声反倒比屋里响。
3. 标书比对类玩法，三份执照与答疑纪要都摊开，不预设谁家得标。

### 开场导语（DM 宣读）
你们守着各自那叠标书坐进比价室时，三家的报价已经从高到低排好，刚好压在预算线里。规则允许答疑澄清，走廊里已经有人低声谈底价了。茶歇时那三张执照并排一摆，谁都多看了一眼。你们各自的说法都摆在台面上，没人替谁确认。今晚要查清的只有一件事：这「价低者得」的一家，该认哪一叠。

### 角色预告
- 标底·苏采购：牵头比价、握着三家答疑纪要，看上去把「程序透明」念得最稳。
- 马甲·潘老板：三家供应商里最低价那家的对接人，看上去只图个长期合作。
- 回扣卡·葛财务：管付款与回扣卡入账，看上去只认合同、不多问一句。

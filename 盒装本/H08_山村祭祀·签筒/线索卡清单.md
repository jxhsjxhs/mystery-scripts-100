# 《山村祭祀·签筒》· 线索卡清单（DM / 印制用）

> 共 5 张线索卡，另有《线索卡.png》组图可直接裁切印刷。

## 线索卡内容
1. 签筒底一枚可抽动的竹夹片，签枝尾端灌了铅，配重明显偏向「外姓」那一签。
2. 祭簿历年「送福人」栏，刀痕数与签枝刻痕一一对应，从未真正随机。
3. 岩叔新糊傩面内衬半张焦边地契，写着塌坡那年寨里分赔的数目。
4. 四盏松明灯芯被同时按矮、留一圈指印烟痕，正是「神签」抽出那一刻。
5. 阿萤守灯簿夹着一页撕下的旧名册，兄长名字被朱笔圈在「塌坡」那栏。

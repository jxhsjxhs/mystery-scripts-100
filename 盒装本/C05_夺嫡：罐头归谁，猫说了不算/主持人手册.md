# 《夺嫡：罐头归谁，猫说了不算》· 主持人手册（DM 专用 · 玩家勿看）

## 〇、商业化包装（宣传 / 开本导语，无剧透）
- 一句话卖点：一罐金枪鱼贴了临朝托管诏，诏书却多出三个牙印和一行猫爪写的「本喵弃权」。
- 上架分类：沙雕·宠物夺嫡罐头 / 3 人 / 入门 / 60–90 分钟

### 盒背文案
铲屎官出差前留了罐金枪鱼罐头，贴一张《临朝托管诏》：三只宠物共管，罐头「待最有德者启」。当晚诏书被啃出三个牙印，旁边多出一行猫爪蘸印泥踩的「本喵弃权」；阳台监控拍到二十三点整，三个毛影同时扑向罐头又同时急刹，整齐得像排练过。出差人远程把客厅封成「临时朝堂」，请三位「当事人」盘清楚这罐子该怎么分——本朝只审宠物不审人，全程得用主子口气说话。

### 卖点
1. 三人小局、六十分钟起步，爱宠的朋友凑一桌就能开，零门槛。
2. 夺嫡诏书配猫爪弃权，满朝毛孩子沙雕气，开口就学猫叫破冰。
3. 以「轮流应诉」代主子开口，只拼谁学得像，不用真懂半点朝规。

### 开场导语（DM 宣读）
你们三位今晚都坐进了这间「临时朝堂」：罐头还供在中间，《临朝托管诏》上多了三个牙印，印泥里那行爪印谁也没认领。谁替橘猫争、谁替柯基憨、谁躲在屏风后学舌，先都端着主子的架子别松——今晚要闹清楚的，是这罐子按什么规矩分、这朝堂的账该怎么记。爪印摆着，话筒交给你们。

### 角色预告
- 戏精·梅有谱：代橘猫「大黄」应诉，戏袍小领结全套；看上去非替大黄争个稳重正统不可。
- 吃货·苟不理：代柯基「短腿」应诉，兜里全是零食；看上去只爱啃拖鞋、对金枪鱼全无执念。
- 社恐·蔫得柱：代鹦鹉「绿秀才」应诉，躲屏风后学舌；看上去翻来覆去只肯说与我无瓜。

## 一、基本信息
- 题材：沙雕·宠物夺嫡罐头
- 人数：3 人（3 名角色）
- 时长：建议 60–90 分钟 ｜ 难度：入门
- 核心机制：「代主子抢爪印」：DM 摆一罐未开的金枪鱼、一盒印泥和三枚「爪章」（猫爪 / 狗尾 / 鸟喙）。每轮 DM 念一条「朝堂奏报」（监控时间点、牙印位置、漏油痕迹等），三位必须抢着用自家爪章在《托管诏》复刻件上盖一下，并**全程用主子口气**说

## 二、发本顺序
1. 先让玩家抽/选角色，按下列顺序发《角色剧本》与《角色卡》（每人只拿自己那份）：
   - 戏精·梅有谱
   - 吃货·苟不理
   - 社恐·蔫得柱
2. 确认每人都读完且没拿错本，再宣读「全场公开背景」。
3. 线索卡按「建议揭示时机」分幕投放，勿一次性摊开。

## 三、三幕流程详述
- **第一幕**：客厅封朝，DM 发三爪章，三人各用主子口气自报家门并抢盖第一轮，先把「三牙印 / 弃权爪印 / 23:00 齐刹」三桩怪事摆上台面，互相听出「怎么都像替别人圆」。
- **第二幕**：开放「诏书牙印」「印泥爪纹」「监控音频轨」「罐头油痕」四处搜证，抢章不停，拼出「猫宣示主权 / 狗尾巴扫诏 / 鸟改字广播」三线，并发现猫爪印是事后补按的。
- **第三幕**：出差人远程连线（DM 扮）下最后一道《启罐旨》：三人须合拟一句「最有德者」的新定义，且这句定义必须让三只宠物都「没输」、罐头才能合法开启分食。

> 每幕开始：简述本幕目标 → 开放搜证 → 组织一轮轮流发言 → 收束到本幕矛盾点。
> 第三幕末组织投票/指认，再念读《结局卡》。

## 四、线索发放表
1. 《临朝托管诏》原件的三个牙印经比对：第一个猫犬齿印边缘沾着橘色猫粮碎屑（与柜底被扒开的半袋猫粮同批次），另两个牙印其实是一排柯基小牙+一道尾巴扫痕，并非三只各咬一口。
2. 印泥「本喵弃权」爪印的趾垫纹路偏长、带一道毛刷状拖尾，与猫掌标本不符，反而吻合柯基尾巴尖蘸印泥横扫的形态；旁边还留着半枚被人事后按上去的真猫爪（边缘过于完整，像摆拍）。
3. 阳台监控 22:58 音频轨里，鹦鹉连续学舌「待最有罐者启、待最有罐者启」共 11 遍，广播覆盖全屋；23:00:00 三毛影扑出、23:00:01 齐刷刷急刹，时间点与学舌停播完全重合。
4. 罐头封口拉环外侧有一道极细的油痕通向地面，地面油点旁是柯基尾巴扫过的弧线，而拉环本身未被撬动——证明「漏油引馋」是真、「开罐」是假，谁都没真吃到。

## 五、反转与高潮
铺垫：全程把「本喵弃权」当成猫高冷退位的金句，DM 每轮都夸「大黄格局大」。反转一：印泥拖尾 + 摆拍猫爪锁定——「弃权」根本不是猫写的，是柯基尾巴扫出来的，猫那枚完整爪印是有人（代猫应诉的戏精）事后补按上去替主子「保住体面」；所谓「高冷退位」是全场最不社恐的那位替最社恐的场面圆了个谎。反转二：改字广播的绿秀才看似最怕被注意，却把「德」学成「罐」、精准把全屋宠物 23:00 召集齐——它不是旁观者，是整场「排练感」的总导演；而它拼命学舌「与我无瓜」，恰恰因为只要没人单独点它，谁都不会去查音频轨里那 11 遍广播。

## 六、完整真相（含全部角色秘密 · 仅 DM）
各角色秘密与任务：
- **戏精·梅有谱**：秘密＝诏书上第一个牙印是大黄啃的，但它啃完就饱了（偷吃了半袋猫粮），纯粹是「先盖个章宣示主权」，压根没想开罐；任务＝把「啃诏」洗成「御笔圈阅」，保住大黄体面并顺走那半袋猫粮的追认权。
- **吃货·苟不理**：秘密＝23:00 那次「集体急刹」是短腿先带的头——它闻到罐头缝漏油，兴奋到把尾巴扫倒了诏书，印泥「弃权」爪印其实是它尾巴蘸着蹭出来的，猫爪印是事后被摆拍的；任务＝让「漏油」被认定成「罐头自爆」而非「狗先馋」，保住短腿「不贪吃」的人设和兜里零食。
- **社恐·蔫得柱**：秘密＝诏书末尾那行「待最有德者启」被它连夜学舌改成了「待最有『罐』者启」，全楼宠物是听它广播才在 23:00 准时集合扑罐的，它才是「排练感」的源头，却最怕被注意到；任务＝不被发现改过字、不单独发言，让「集合」显得是大家自发的。

真相与证据链：
真相：橘猫大黄啃诏只是「盖章宣示」、啃完偷吃猫粮饱了，压根没想开罐；柯基短腿闻到封口漏油先扑、尾巴扫倒诏书并蹭出「弃权」拖尾，急刹也是它带的头；鹦鹉绿秀才连夜把「最有德者」学成「最有罐者」全屋广播，才有了 23:00 三毛影整齐集合又齐刹的名场面；戏精梅有谱为保大黄体面，事后补按了一枚完整猫爪印把「尾巴扫的弃权」包装成「本喵高冷退位」。罐头自始至终没开，拉环没撬，三只谁都没吃到，纯属一群毛孩子被一句谐音带跑的深夜集体空扑。主结局（新定义）：三人合拟「最有德者 = 闻到漏油没撬环、啃了诏没贪罐、改了字还肯替大家圆场的，都算」，出差人回「准，启罐」，罐头终于开了、三只平分，鹦鹉被特许不用发言只负责复诵「分匀了、分匀了」。分支：若定义里有人非要分出嫡庶，DM 转罐触发「夺嫡回响」终极版——三枚爪章全盖进同一格，辩词由鹦鹉连复诵三遍，罐头转回原位「待下回再议」，笑收。

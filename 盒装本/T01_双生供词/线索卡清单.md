# 《双生供词》· 线索卡清单（DM / 印制用）

> 建议做成 63×88mm 卡片，正面编号 + 物证描述，背面留白。

## 线索卡内容
1. 羁押登记表上「祁宴」签名向左倾、起笔带左手拖痕；警局存档的祁宴笔迹样本右倾，附入职体检表「右手虎口篆刻茧、右耳后色素痣、惯用右手」。
2. 书房裁纸刀柄上只有一枚右手拇指指纹，与存档祁宴样本吻合；而被告入所体检写明「惯用左手、右手无茧、右耳后光洁」，指纹与收押者并非同一人。
3. 兄弟合影背面题「宴左昼右」：左侧青年左腕戴表、右耳后有痣，右侧青年右腕戴表；会见录像里「被告」右腕戴表、右耳后光洁。
4. 21：30 津浦线实名「祁昼」高铁票一张，未检票、未退票，票根夹在浅色外套内袋；同夜 22：10 巡捕房证人笔录末尾签名却是「祁昼」。
5. 21：33 书房座机录音：老仆喊「昼少爷，老爷请您上去」，接听者答「我是宴，昼已经出门了」，背景座钟报九点三十三分。

## 印制建议
- 每条线索单独制卡；编号与《线索卡.png》一一对应。
- 物证类可配实物道具（纸张、票据、照片、器物）提升沉浸。
- 线索须能被搜到、可被回看验证；DM 不要提前放完，按幕逐步解锁。

# 《直播翻车之：带货的是我，翻的是我》· 角色剧本 —— 吃货·侯补榜

> 本册**仅发给「吃货·侯补榜」的玩家**，请勿传阅、不要让其他玩家看到。
> 本局 4 人 ｜ 建议 60–90 分钟 ｜ 难度 进阶

## 一、你是谁
场务兼「榜一大哥」替身，兜里揣着试吃小零食

## 二、全场公开背景（DM 开场宣读，所有人都知道）
「不翻不散」直播间卖「全自动静音鼓掌机」，主播喊完「上链接」同一秒，999+ 条弹幕齐变「已鼓掌」，鼓掌机样品「啪」地合上、夹住主播袖口，背景音飘出「感谢家人们，本场由我代播」。后台更离谱：本场「成交 0 单、鼓掌 999 次、在线人数 1」，那 1 个 IP 登记在样品机名下。平台封直播间作「复盘室」，四人盘清楚：链接谁上的、弹幕谁刷的、「代播」谁配的音。复盘期间不许说「卡了」，一说罚重念口播稿。

## 三、你在人前的主张
举着手机自证「我就挂了个机、啃了个蛋黄酥，啥也没点」

## 四、只有你知道的秘密（切勿主动说出）
直播间那个「在线人数 1 / IP 归属样品机」是他弄的——他怕主播冷场没人气，拿样品机的测试账号挂了个「常驻观众」充门面，顺手把账号昵称改成「家人们」，才让批量弹幕显得「有人回」

## 五、你的任务（本局要达成的个人目标）
**让「1 个在线」被当成「平台计数故障」，保住蛋黄酥和「我从没刷过榜」的清白。**

## 六、你开场掌握的信息
- 你的身份、上述秘密与任务；
- 全场公开背景；
- 其余线索须在搜证轮获得，不要预设别人手里有什么。

## 七、分幕行动指引
- 第一幕：复盘室落座，DM 发按钮板，四人抢拍认领「上链接 / 弹幕 / 在线 / 代播」四环节，先用口播腔各辩一句，把「成交 0 / 鼓掌 999 / 在线 1 / 袖口被夹」四桩怪账摆上台，且全员被禁词「卡了」憋得开始互相递纸条。
- 第二幕：开放「音频波形」「气氛组改词日志」「快捷键映射」「在线列表快照」四处搜证，抢拍不停、禁词一滑就集体重念口播稿，拼出「主播误碰 / 场控绑键 / 场务挂机 / 审核改词」四线，并发现 999 弹幕与链接是同一次按键。
- 第三幕：平台要求合交一份《本场复盘口播终稿》，四人须共用一张提词卡、每人只写一行、四行连起来必须同时解释「0 单却 999 捧场」「1 个在线是谁」「代播那句谁说的」，且全稿不得出现禁词，念完即解封。

## 八、你要隐瞒 / 你要追查
- **隐瞒**：直播间那个「在线人数 1 / IP 归属样品机」是他弄的——他怕主播冷场没人气，拿样品机的测试账号挂了个「常驻观众」充门面，顺手把账号昵称改成「家人们」，才让批量弹幕显得「有人回」 —— 用对话与搜证周旋，别一上来就摊牌。
- **追查**：与「让「1 个在线」被当成「平台计数故障」，保住蛋黄酥和「我从没刷过榜」的清白。」相关的物证、他人证词里的矛盾、时间线缺口。

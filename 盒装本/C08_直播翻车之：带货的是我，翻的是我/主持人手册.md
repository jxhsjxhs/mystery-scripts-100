# 《直播翻车之：带货的是我，翻的是我》· 主持人手册（DM 专用 · 玩家勿看）

## 〇、商业化包装（宣传 / 开本导语，无剧透）
- 一句话卖点：主播刚喊上链接，样品鼓掌机「啪」地夹住袖口，背景音还替全场道了谢。
- 上架分类：沙雕·直播样品机代播 / 4 人 / 进阶 / 60–90 分钟

### 盒背文案
「不翻不散」直播间卖「全自动静音鼓掌机」，主播喊完「上链接」同一秒，九百九十九条弹幕齐变「已鼓掌」，样品机「啪」地合上夹住主播袖口，背景音飘出「感谢家人们，本场由我代播」。后台更离谱：本场「成交 0 单、鼓掌 999 次、在线人数 1」。平台把直播间封成「复盘室」，请四位盘清楚这链接、这弹幕、这声道是怎么回事——复盘期间不许说「卡了」，一说罚重念口播稿。

### 卖点
1. 四人一桌、九十分钟一局，带货梗爱好者凑齐就开，进阶不烧脑。
2. 零成交却满屏捧场，样品机抢着代播，一开口就是满屋弹幕味。
3. 以「复盘接龙」轮流对口播，只比谁接得稳，不用懂半点设备。

### 开场导语（DM 宣读）
你们四位今晚都被请进了这间「复盘室」：样品机还夹着袖口，弹幕停在九百九十九条「已鼓掌」，后台那行「在线人数 1」谁看了都挠头。链接谁上的、弹幕谁刷的、那句代播谁配的音，先别急着认也别急着推——今晚要闹清楚的，是这场复盘该怎么记、口播稿还得重念几遍。补光开着，话筒交给你们。

### 角色预告
- 显眼包·播必火：本场主播，全套打光补妆；看上去痛心疾首要查谁抢了麦、口播一字没崩。
- 摸鱼·秦点链：场控兼运营，摸鱼时把脚搭控制台上那种；看上去只肯管弹幕、链接一概不认。
- 吃货·侯补榜：场务兼「榜一大哥」替身，兜里揣试吃小零食；看上去举着手机自证只挂了机。
- 社恐·弹幕菌：弹幕审核员，躲显示器后只打字不吭声；看上去便签上翻来覆去就一句别问我。

## 一、基本信息
- 题材：沙雕·直播样品机代播
- 人数：4 人（4 名角色）
- 时长：建议 60–90 分钟 ｜ 难度：进阶
- 核心机制：「禁词抢麦复盘」：DM 摆一只玩具鼓掌机、一块「上链接」按钮板和一叠弹幕纸条。每轮 DM 念一条后台记录（时间戳、弹幕内容、在线 IP、音频轨），四位必须抢着拍一下按钮板「认领环节」，拍到的人用一句口播腔辩解、且**绝不能说出「卡了」二字*

## 二、发本顺序
1. 先让玩家抽/选角色，按下列顺序发《角色剧本》与《角色卡》（每人只拿自己那份）：
   - 显眼包·播必火
   - 摸鱼·秦点链
   - 吃货·侯补榜
   - 社恐·弹幕菌
2. 确认每人都读完且没拿错本，再宣读「全场公开背景」。
3. 线索卡按「建议揭示时机」分幕投放，勿一次性摊开。

## 三、三幕流程详述
- **第一幕**：复盘室落座，DM 发按钮板，四人抢拍认领「上链接 / 弹幕 / 在线 / 代播」四环节，先用口播腔各辩一句，把「成交 0 / 鼓掌 999 / 在线 1 / 袖口被夹」四桩怪账摆上台，且全员被禁词「卡了」憋得开始互相递纸条。
- **第二幕**：开放「音频波形」「气氛组改词日志」「快捷键映射」「在线列表快照」四处搜证，抢拍不停、禁词一滑就集体重念口播稿，拼出「主播误碰 / 场控绑键 / 场务挂机 / 审核改词」四线，并发现 999 弹幕与链接是同一次按键。
- **第三幕**：平台要求合交一份《本场复盘口播终稿》，四人须共用一张提词卡、每人只写一行、四行连起来必须同时解释「0 单却 999 捧场」「1 个在线是谁」「代播那句谁说的」，且全稿不得出现禁词，念完即解封。

> 每幕开始：简述本幕目标 → 开放搜证 → 组织一轮轮流发言 → 收束到本幕矛盾点。
> 第三幕末组织投票/指认，再念读《结局卡》。

## 五、反转与高潮
铺垫：全程把「样品机成精代播」当头号悬案，DM 每轮都郑重问「机器本人还有何补充」，鼓掌机偶尔还自己「啪」一声。反转一：波形+袖口摩擦锁定——「代播」是主播自己录的垫场音被误碰播放，「夹袖口」是他演示静音时主动凑太近，样品机连麦都没插；而「999 已鼓掌」也不是观众刷的，是场控把模板和「上链接」绑同一键、主播一喊「上」就双发。所谓「直播翻车」，其实是四个人各自为了「别冷场」提前铺好的台阶，在同一秒全被踩响，整齐得像排练过。反转二：最不吭声的弹幕菌才是全场唯一一次「主动开口」的人——他看见成交 0 单、怕主播当场挂不住，连夜把气氛组默认词从「已下单」改成「已鼓掌」，用不说话的方式替全场圆了「没人买但大家都很捧场」；他递的「我一条没发」字面全对（他改的是模板、没发弹幕），却恰好是整场「999 捧场」的源头。

## 六、完整真相（含全部角色秘密 · 仅 DM）
各角色秘密与任务：
- **显眼包·播必火**：秘密＝那句「本场由我代播」是他提前录好的备用垫场音，本想万一冷场就放来撑场面，结果上链接时误碰了播放键；袖口被夹也是他为了演示「静音」自己把样品机往袖口凑太近；任务＝把「误碰+自夹」圆成「样品机主动代播」，保住「零翻车主播」的招牌和下一场坑位。
- **摸鱼·秦点链**：秘密＝999+ 条「已鼓掌」是他用后台「气氛组模板」一键批量发的，本想省得盯屏，顺手把「上链接」按钮也设成了同组快捷键，主播一喊「上」就触发了模板+链接双发；任务＝把「一键批量」认定成「系统气氛组自动行为」，保住自己没离岗的全勤，最好连复盘都别记他名。
- **吃货·侯补榜**：秘密＝直播间那个「在线人数 1 / IP 归属样品机」是他弄的——他怕主播冷场没人气，拿样品机的测试账号挂了个「常驻观众」充门面，顺手把账号昵称改成「家人们」，才让批量弹幕显得「有人回」；任务＝让「1 个在线」被当成「平台计数故障」，保住蛋黄酥和「我从没刷过榜」的清白。
- **社恐·弹幕菌**：秘密＝他才是把「已鼓掌」模板文案从「已下单」改掉的人——他看见成交 0 单怕主播当场尴尬，又不敢开口提醒，就连夜把气氛组默认词改成「已鼓掌」，想让「没人买」至少看着像「大家都很捧场」；任务＝不被发现改过默认词、不发言、不被拉进连麦，安全下播。

真相与证据链：
真相：主播播必火备了「本场由我代播」垫场音防冷场，上链接时误碰播放键、又凑太近被样品机夹住袖口，造出「机器代播」名场面；场控秦点链 19:58 把「气氛组模板」和「上链接」绑同一组合键图省事，主播一喊「上」同毫秒双发 999 条弹幕+链接；场务侯补榜 19:40 拿样品机测试账号挂「常驻观众」、改昵称「家人们」充门面，自己啃蛋黄酥没点任何东西；审核弹幕菌 19:12 看见成交 0 单怕尴尬，把模板默认词「已下单」改成「已鼓掌」，全程只改词、没发一条弹幕、没说一句话。于是后台成「成交 0 单、鼓掌 999 次、在线 1（还是台机器）」。没有翻车，只有四个人用四种「少尴尬一点」的方式，把同一秒叠成了事故。主结局（四行终稿）：提词卡写「① 捧场 999 为气氛组默认词，非下单、非刷屏 ② 唯一在线是样品机挂机围观，家人们是它昵称 ③ 代播句为主播备用垫场音误触，机器未插麦 ④ 本场零成交但零冷场，静音鼓掌机确实静音」——全稿无禁词，平台解封，样品机被授「本场最佳观众」，弹幕菌的便签被裱成「最省话的救场」。分支：若终稿里有人嘴滑说出「卡了」，DM 打板「代播回响」终极版，四人集体重念口播稿 999 遍里的「前三遍」，鼓掌机「啪」地替他们收尾，笑着下播。

## 八、节奏与安全提示
- 防冷场：开场先由 DM 自己拍板、用浮夸口播腔辩「这正说明……机器比我会控场」，再故意嘴滑说一次「卡了」触发集体重念，把「禁词」的羞耻感先替全场踩碎。
- 发梗时机：每有人踩禁词就打板领念「全自动静音鼓掌机，不鼓不散」；每次两人同拍就放「本场由我代播」并让社恐用便签写统一辩词，累计三张便签正式给他挂「本场首席嘴替（不用张嘴）」纸牌。
- 揭「改词的是弹幕菌」压到第二幕末尾，先让四人围着「样品机成没成精」猜够两轮、主播把「零翻车」吹满，再翻 19:12 改词日志——最安静的那位才是刀口，轻放、不冒犯、笑完还暖。

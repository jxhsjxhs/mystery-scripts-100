# 《穿成道具之后，我成了本案唯一证人》· 盒面文案 / 宣传物料

> 可直接用于电商详情页、盒背、海报、店铺介绍；**严禁剧透**（不写真相/反转/凶手）。

- 一句话卖点：本该摔碎的青瓷茶盏滚到监视器前，盏底用茶渍显出五个字「别摔我啊」。
- 上架分类：沙雕·道具成精作证 / 3 人 / 进阶 / 60–90 分钟

### 盒背文案
剧组拍古装宅斗的收尾大戏，道具间深夜「闹道具」：本该在第 3 场摔碎的青瓷茶盏非但没碎，还滚到监视器前，盏底用茶渍显出「别摔我啊」；场记板上「第 3 场 / 摔盏」被改成了「第 3 场 / 盏自辩」，清单背面多一行小字：「今夜在场能说话的，只有不会说话的那几件」。导演锁了道具间，让三位「当事人」把这事盘清楚。三位玩家各扮一件道具，不许说「我是人」，只以物件的视角开口作证。

### 卖点
1. 三人一桌、九十分钟一局，戏精聚会抬手就开，进阶也玩得轻松。
2. 茶盏写字、场记板改词，满屋道具成精的奇想，一开口就抢着演。
3. 以「物件作证」轮番开口，只比谁演得像，不用拆半点机关。

### 开场导语（DM 宣读）
你们三位今晚都被锁在了道具间：监视器前那只茶盏还好好地躺着，盏底那行茶渍没干，场记板上的场次被人改过一笔。谁最该被镜头对准、谁只想滚回垫子、谁躲在角落不敢展开，先都别急着替谁作保——今晚要闹清楚的，是这道具间怎么个「闹」法、这场戏还按不按原样拍。灯亮着，话筒交给你们。

### 角色预告
- 显眼包·镜必亮：扮演「手柄镶钻的补光反光板」，全场最闪；看上去非要争回最该被镜头对准的位置。
- 摸鱼·简躺平：扮演「第 3 场该被摔的青瓷茶盏」本人；看上去只想滚回垫子装个安静的盏。
- 社恐·幕后人：扮演「一块总被叠在角落的幕布」，说话只敢用褶子比划；看上去全程没展开、啥也不肯说。

# 《全公司锦鲤附体，只有我越转越衰》· 盒面文案 / 宣传物料

> 可直接用于电商详情页、盒背、海报、店铺介绍；**严禁剧透**（不写真相/反转/凶手）。

- 一句话卖点：全公司三十六人转锦鲤都领了顺遂奖，独打印机旁那位连转九次全弹回弹。
- 上架分类：沙雕·锦鲤转发回弹 / 2 人 / 入门 / 60–90 分钟

### 盒背文案
「鸿运科技」晨会转发锦鲤迎周报，行政群发一张胖锦鲤图。一上午全公司三十六人全转、人人领到顺遂奖品，唯独工位靠打印机的那位连转九次、九次都弹「转发失败·运势回弹」，还把打印机卡纸、咖啡机溢杯、增氧泵停摆全揽了。锦鲤图的文件属性里藏着一句备注：「本鲤只渡不缺顺的人」。行政锁了茶水间，让两位当事人把这事盘清楚：一个证玄学有效，一个证玄学没效，可每条物证都在帮对方说话。

### 卖点
1. 两人就能开、六十分钟起步，办公室饭后随手一局，零门槛。
2. 全员皆顺独一人连衰，锦鲤玄学沙雕到拍桌，社恐看了都乐。
3. 以「物证比对」轮流举证，只比谁圆得巧，不用真信半点玄学。

### 开场导语（DM 宣读）
你们两位今晚都被留在了茶水间：胖锦鲤图还挂在群里，一叠「回弹」截图摊在桌上，打印机卡着的纸也没人去抽。谁笃信转发就顺、谁认定自己被精准针对，先别急着说服对方——今晚要闹清楚的，是这九次回弹该怎么记、这杯没溢的咖啡该不该赔。杯子摆着，话筒交给你俩。

### 角色预告
- 欧皇·欧得稳：行政兼「锦鲤仪式」发起人，自带抽啥中啥体质；看上去誓要守住转发即顺遂的规矩。
- 摸鱼·梅顺遂：工位紧挨打印机的倒霉蛋，名字叫顺遂、日子最不顺；看上去拍桌只求赔一杯没溢的咖啡。

# 《蜡像馆·指温》· 线索卡清单（DM / 印制用）

> 共 5 张线索卡，另有《线索卡.png》组图可直接裁切印刷。
> 建议做成 63×88mm 卡片，正面编号 + 物证描述，背面留白。

## 线索卡内容
1. 撑伞女像右手指腹一处软凹，边缘有指纹旋纹，是按温不是凝裂。
2. 伞柄根部有细刻度，三夜各偏半寸，刻度是刀尖新划的。
3. 壁灯只一盏，展厅地面却有一道被踩亮的布鞋印，正落在「多一截影」处。
4. 女像底座螺丝新拧过，撬开见空腔，里头一纸折起的旧契。
5. 阿炉更房一张字条：「伞偏则契在，勿点二灯」，笔迹与馆主稿纸不同。

## 印制建议
- 每条线索单独制卡；编号与《线索卡.png》一一对应。
- 物证类可配实物道具（纸张、票据、照片、器物）提升沉浸。
- 线索须能被搜到、可被回看验证；DM 不要提前放完，按幕逐步解锁。

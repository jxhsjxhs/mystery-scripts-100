# 《纸扎铺·烧给谁》· 线索卡清单（DM / 印制用）

> 共 5 张线索卡，另有《线索卡.png》组图可直接裁切印刷。
> 建议做成 63×88mm 卡片，正面编号 + 物证描述，背面留白。

## 线索卡内容
1. 主顾红纸写的是生辰八字而非名讳，与旧簿三年前那页生辰一字不差。
2. 旧簿同页「报死」名册里，该生辰下名字被刮改过、残笔仍可辨。
3. 纸扎里糊了灶台与纸童——按行规「续阳堂」才有灶，给亡人的不糊。
4. 纸童眼上两点新墨，与篾青指腹墨色、袖口墨渍一致。
5. 芮娘带来的半根旧纸骨，断口与今夜铺里纸骨同批篾刀痕。

## 印制建议
- 每条线索单独制卡；编号与《线索卡.png》一一对应。
- 物证类可配实物道具（纸张、票据、照片、器物）提升沉浸。
- 线索须能被搜到、可被回看验证；DM 不要提前放完，按幕逐步解锁。

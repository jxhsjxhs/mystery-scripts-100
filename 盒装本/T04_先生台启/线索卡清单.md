# 《先生台启》· 线索卡清单（DM / 印制用）

> 共 5 张线索卡，另有《线索卡.png》组图可直接裁切印刷。
> 建议做成 63×88mm 卡片，正面编号 + 物证描述，背面留白。

## 线索卡内容
1. 尸检报告第四行（结案摘要漏抄）：「骨盆入口呈女性型，喉结缺如，颈部有珍珠胸针刺痕；死亡时间 19：30–20：00」——死亡早于监控 20：40 的「入场」至少四十分钟。
2. 外版委托书签名栏用的是专指女性的抬头，俞泠被删去的译注写着「原文为女称谓，中译从旧例作『先生』，尊称不分男女」；中译本抬头却作「祁先生 台启」。
3. 20：40 与 21：05 两帧截图里，两人右手背同一位置都有一块烫伤疤、都先迈左脚；21：05「女子」假发下露出的发际线与 20：40「男子」的短发完全同形。
4. 资料室垃圾桶证物袋：一束剪下的长发、一副假发网套、一只被酸液蚀坏却仍留着珍珠托座的胸针，与尸检颈部刺痕吻合。
5. 监控镜像备份仍在（霍铎报损的是母带），20：52–21：03 片段里只有一人在室内走动、换装，并两次把同一只右手伸向灯开关。

- 每条线索单独制卡；编号与《线索卡.png》一一对应。

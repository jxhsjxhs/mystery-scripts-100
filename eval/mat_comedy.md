# 搞笑本 · 零剧透评审素材（C01–C25）

> 仅供学生评审 agent 使用。本表已剔除真相/反转/结局/隐藏秘密。
> 严禁打开终稿全文或主持人手册。评语要印在盒面上，读完只想买、猜不出答案。

## [C01] 《年会锦鲤，但奖品是老板》
- 一句话卖点：年会特等奖写着与老板共游一日，开奖前奖箱却自己多出一张金鲤怪券。
- 上架分类：沙雕·年会锦鲤错奖 / 2 人 / 入门 / 60–90 分钟
- 公开背景：公司年会摆开「阳光抽奖」，特等奖写着「与老板共进私人定制一日游」。开奖前一分钟，奖箱里凭空多出一张烫金边、只画胖锦鲤的怪券；大屏随即卡成表情包，全公司手机同时蹦出同一条匿名短信：「别抽了，中特等奖的人会被老板认领」。更离谱的是，老板正缩在后台道具间，一口咬定没设过这奖，直说「锦鲤先动的手」。偌大会场只剩两个被锁在场的人，这奖还抽不抽，一时谁也拿不准。
  - 摸鱼·甄划水：行政兼抽奖主持，摸鱼界劳模；看上去誓要把年会流程的公正盯到底。
  - 锦鲤·郝运来：前台，自带「抽啥中啥」体质；看上去只想领了奖准点下班追剧。

## [C02] 《一颗五星，差评侠与好评怪》
- 一句话卖点：同一单砂锅被连刷二十七次差评又二十七次好评，小店直接被系统冻了提现。
- 上架分类：沙雕·咸淡差好评互刷 / 3 人 / 入门 / 60–90 分钟
- 公开背景：「旺德福砂锅」小店某天炸了锅：后台同一单被连点二十七次「一星差评」，又连点二十七次「五星好评」，评语清一色「太咸」「太淡」「咸淡刚刚好」循环刷屏，系统把店标判成「薛定谔的口味」还冻了提现。骑手取餐箱里更多出一张小票，背面写着「别查了，这单是我自己跟自己打起来的」。老板关门把在场三位锁进堂食区：不盘清这二十七轮咸淡公案谁也别走，连那只被误登记成「本店口味总监」的橘猫也算在内。
  - 群主·彭友圈：本地吃喝群的群主，店里的「民间舆情办」；看上去非要揪出刷评的手才肯罢休。
  - 戏精·白加黑：店里的兼职服务生，戏比砂锅还满；看上去护店护到动不动就捂胸口念台词。
  - 吃货·甄能吃：当天唯一真实下单的顾客，人形砂锅探测仪；看上去只想要一份正常咸淡的重做。

## [C03] 《相亲角，我妈和我是同一个人》
- 一句话卖点：一张优质男嘉宾资料卡，一上午被四位家长认领，打卡钟却只吐出「到场一人」。
- 上架分类：沙雕·相亲角一人四认 / 4 人 / 进阶 / 60–90 分钟
- 公开背景：城南公园相亲角，同一张「优质男嘉宾」资料卡一上午被四位家长同时认领：照片是同一人，署名却写成「本人」「本人母亲」「本人小姨」「本人本人」四款，爱好栏涂成「爱静」「爱闹」「爱静闹结合」「爱被安排」。凉亭老式打卡钟每逢整点「咔」地吐出小票：「本时段到场人数：1，登记人次：4」。红娘摊主一拍桌：不把「到底来了几位、谁才是真身」盘明白，谁都别摘胸花。四位「家长」面面相觑，谁也不肯先挪步。
  - 群主·孟美琪：相亲角信息群群主，手持喇叭的统筹担当；看上去非要把登记秩序一寸寸捋直。
  - 社恐·温吞水：被安排来相亲的本人，全程想把自己缩进折扇；看上去只当是陪小姨来逛逛。
  - 戏精·佟排场：自称「小姨」，戏服胸花全套；看上去嫌资料卡太素、当场就要加才艺栏。
  - 显眼包·贾大方：自称「本人母亲」，拎着最大号保温壶；看上去逢人便夸自家条件好、卡是亲手填的。

## [C04] 《业主群今晚不许发「收到」》
- 一句话卖点：静音实验刚开场，群里「收到」刷了九十九条，系统却全算在三栋五零二头上。
- 上架分类：沙雕·业主群收到刷屏 / 4 人 / 进阶 / 60–90 分钟
- 公开背景：「和风雅苑 3 栋业主群」立了新规：今晚二十点到二十一点是「静音实验」，发一句「收到」罚充十元公共电费。整点一到，群里「收到」刷了九十九条，系统齐刷刷标成「由 3 栋 502 转发」，可 502 业主坚称手机整晚扣在物业前台充电。物业把四位当事人请进活动室，桌上摆着旧路由器、群聊截图和一张《静音实验值日表》：不盘清这九十九条谁发的，谁也拿不回暂扣的手机。
  - 群主·娄一鸣：业主群群主，规则发起人；看上去痛心疾首要守住静音实验的规矩。
  - 摸鱼·司徒躺：物业夜班保安，摸鱼学博士后；看上去只肯管那台路由器、绝不碰手机。
  - 社恐·甄别点：302 业主，最怕被点名；看上去一条都不想发、也不想被拉进讨论。
  - 显眼包·包你亮：楼下便利店老板，群里的表情包大王；看上去举着手机非要自证只发了一条。

## [C05] 《夺嫡：罐头归谁，猫说了不算》
- 一句话卖点：一罐金枪鱼贴了临朝托管诏，诏书却多出三个牙印和一行猫爪写的「本喵弃权」。
- 上架分类：沙雕·宠物夺嫡罐头 / 3 人 / 入门 / 60–90 分钟
- 公开背景：铲屎官出差前留了罐金枪鱼罐头，贴一张《临朝托管诏》：三只宠物共管，罐头「待最有德者启」。当晚诏书被啃出三个牙印，旁边多出一行猫爪蘸印泥踩的「本喵弃权」；阳台监控拍到二十三点整，三个毛影同时扑向罐头又同时急刹，整齐得像排练过。出差人远程把客厅封成「临时朝堂」，请三位「当事人」盘清楚这罐子该怎么分——本朝只审宠物不审人，全程得用主子口气说话。
  - 戏精·梅有谱：代橘猫「大黄」应诉，戏袍小领结全套；看上去非替大黄争个稳重正统不可。
  - 吃货·苟不理：代柯基「短腿」应诉，兜里全是零食；看上去只爱啃拖鞋、对金枪鱼全无执念。
  - 社恐·蔫得柱：代鹦鹉「绿秀才」应诉，躲屏风后学舌；看上去翻来覆去只肯说与我无瓜。

## [C06] 《穿成道具之后，我成了本案唯一证人》
- 一句话卖点：本该摔碎的青瓷茶盏滚到监视器前，盏底用茶渍显出五个字「别摔我啊」。
- 上架分类：沙雕·道具成精作证 / 3 人 / 进阶 / 60–90 分钟
- 公开背景：剧组拍古装宅斗的收尾大戏，道具间深夜「闹道具」：本该在第 3 场摔碎的青瓷茶盏非但没碎，还滚到监视器前，盏底用茶渍显出「别摔我啊」；场记板上「第 3 场 / 摔盏」被改成了「第 3 场 / 盏自辩」，清单背面多一行小字：「今夜在场能说话的，只有不会说话的那几件」。导演锁了道具间，让三位「当事人」把这事盘清楚。三位玩家各扮一件道具，不许说「我是人」，只以物件的视角开口作证。
  - 显眼包·镜必亮：扮演「手柄镶钻的补光反光板」，全场最闪；看上去非要争回最该被镜头对准的位置。
  - 摸鱼·简躺平：扮演「第 3 场该被摔的青瓷茶盏」本人；看上去只想滚回垫子装个安静的盏。
  - 社恐·幕后人：扮演「一块总被叠在角落的幕布」，说话只敢用褶子比划；看上去全程没展开、啥也不肯说。

## [C07] 《全公司锦鲤附体，只有我越转越衰》
- 一句话卖点：全公司三十六人转锦鲤都领了顺遂奖，独打印机旁那位连转九次全弹回弹。
- 上架分类：沙雕·锦鲤转发回弹 / 2 人 / 入门 / 60–90 分钟
- 公开背景：「鸿运科技」晨会转发锦鲤迎周报，行政群发一张胖锦鲤图。一上午全公司三十六人全转、人人领到顺遂奖品，唯独工位靠打印机的那位连转九次、九次都弹「转发失败·运势回弹」，还把打印机卡纸、咖啡机溢杯、增氧泵停摆全揽了。锦鲤图的文件属性里藏着一句备注：「本鲤只渡不缺顺的人」。行政锁了茶水间，让两位当事人把这事盘清楚：一个证玄学有效，一个证玄学没效，可每条物证都在帮对方说话。
  - 欧皇·欧得稳：行政兼「锦鲤仪式」发起人，自带抽啥中啥体质；看上去誓要守住转发即顺遂的规矩。
  - 摸鱼·梅顺遂：工位紧挨打印机的倒霉蛋，名字叫顺遂、日子最不顺；看上去拍桌只求赔一杯没溢的咖啡。

## [C08] 《直播翻车之：带货的是我，翻的是我》
- 一句话卖点：主播刚喊上链接，样品鼓掌机「啪」地夹住袖口，背景音还替全场道了谢。
- 上架分类：沙雕·直播样品机代播 / 4 人 / 进阶 / 60–90 分钟
- 公开背景：「不翻不散」直播间卖「全自动静音鼓掌机」，主播喊完「上链接」同一秒，九百九十九条弹幕齐变「已鼓掌」，样品机「啪」地合上夹住主播袖口，背景音飘出「感谢家人们，本场由我代播」。后台更离谱：本场「成交 0 单、鼓掌 999 次、在线人数 1」。平台把直播间封成「复盘室」，请四位盘清楚这链接、这弹幕、这声道是怎么回事——复盘期间不许说「卡了」，一说罚重念口播稿。
  - 显眼包·播必火：本场主播，全套打光补妆；看上去痛心疾首要查谁抢了麦、口播一字没崩。
  - 摸鱼·秦点链：场控兼运营，摸鱼时把脚搭控制台上那种；看上去只肯管弹幕、链接一概不认。
  - 吃货·侯补榜：场务兼「榜一大哥」替身，兜里揣试吃小零食；看上去举着手机自证只挂了机。
  - 社恐·弹幕菌：弹幕审核员，躲显示器后只打字不吭声；看上去便签上翻来覆去就一句别问我。

## [C09] 《一分钱手气王》
- 一句话卖点：七轮拼手气红包连发，手气王得翻倍续包，常年抢一分钱的那位慌了。
- 上架分类：沙雕·红包手气王甩锅 / 2 人 / 入门 / 60 分钟
- 公开背景：腊月二十八，公司「摸鱼互助群」忽然弹出一条群公告：今晚拼手气红包连发七轮，手气王必须接着续包、金额还得翻倍，说是给大伙攒个开门红。群主钱秒光把规则念得比年会还郑重，可常年抢到一分钱的非酋甄不中越听越心慌——他明明练过抢包脚本，今晚却一次都没敢点开。灯一关，七轮红包、两部手机、一张被撤回的专属提示，把小小的群聊挤成了沙雕修罗场，谁都想把手气王这顶帽子往对面推。
  - 非酋·甄不中：群里公认的运气黑洞，连阳光普照奖都能抽成谢谢参与；看上去只求大家别再让他续包。
  - 打工人·钱秒光：群主兼红包发起人，工资到账三秒清空；看上去张罗开门红纯为热闹、分毫不占。

## [C10] 《十八楼没有领导》
- 一句话卖点：早高峰电梯卡在九楼与十八楼之间，按钮上多了张「十八楼领导专用」的手写便签。
- 上架分类：沙雕·静音楼层假领导 / 3 人 / 入门 / 60 分钟
- 公开背景：周一早高峰，写字楼那部老电梯卡在九楼与十八楼之间，门一开，社恐打工人、隔壁店长、爱播报八卦的课代表被塞进同一格轿厢。按钮上不知谁贴了张「十八楼领导专用」的手写便签，三人瞬间进入汇报状态：挺胸、憋笑、抢着按楼层。真领导偏巧请假没到岗，电梯每停一层，误会便叠高一层，谁都不敢先认自己只是来送个早餐。
  - 打工人·苟住：见领导就自动贴墙的社恐职员，兜里还揣着代带的早餐；看上去绝不主动按任何楼层。
  - 店长·郝威严：隔壁门店店长，嗓门大、走路带风，最像微服私访；看上去顺势端着、挺享受这场汇报。
  - 课代表·全知道：全楼八卦中转站，电梯里也不肯闭嘴；看上去忙着替大家引荐、一口咬定认得真领导。

## [C11] 《八组也没兜住》
- 一句话卖点：深夜一句「加班到想原地退休」分了八组发出去，广场舞队和甲方却都冒了头。
- 上架分类：沙雕·分组可见翻车 / 4 人 / 入门 / 60 分钟
- 公开背景：深夜十一点，课代表把朋友圈切成八个分组，发出一句「加班到想原地退休」，自以为只对同事可见。结果广场舞领队甩来一排队形表情包，甲方秒回「按上一版可见范围再改一版」，卖茶姐店长更在两个组里同时冒了头。四个人隔着屏幕面面相觑：分组名单、共同好友、一条谁都没删的旧动态，把本该安静的吐槽搅成了一场全员在场的朗读会，谁都想先把那条动态摘干净。
  - 课代表·分八组：把人际关系切成八张名单的分组狂魔，备忘录比通讯录还厚；看上去坚称自己手滑、只把吐槽发给了同事组。
  - 店长·卖茶姐：白天卖茶、夜里刷屏的社群活跃分子，两个组里都有她；看上去一脸无辜、只当刚好刷到。
  - 广场舞·李领舞：队伍排得比谁都齐，表情包也发得比谁都快；看上去声称只是路过点赞、没看懂那条吐槽。
  - 甲方·改八版：把可见范围当方案反复改的需求方，句句带「上一版」；看上去咬定自己是被误发的、催着立刻撤回。

## [C12] 《暗号没有上一页》
- 一句话卖点：交接手册头一页写着「暗号等于上一页答案加一」，可全店谁也翻不出上一页。
- 上架分类：沙雕·暗号接力反传 / 3 人 / 入门 / 60 分钟
- 公开背景：街角奶茶店真店长交钥匙出门相亲，留下一本「今日交接手册」和一句「照着暗号接单就行」。外卖跑单王、临时替班打工人，加上半路折回拿充电器的店长本人，轮番站到同一台点单机后头。手册第一页写着「暗号＝上一页答案加一」，谁也翻不出上一页；一单「不要葱」传到第三个人嘴里成了「多放葱」。订单没出错几张，口头禅倒传出了三个版本。
  - 店长·交钥匙：出门相亲还不忘留手册的真店长，最信流程不会骗人；看上去坚称手册天衣无缝、出错全怪代班不用心。
  - 外卖·跑单王：送单顺路被抓来顶班的跑单老手，外箱里油渍比订单还多；看上去咬定「不要葱」是上一位说错的。
  - 打工人·临时替：今天第三次临时上岗，围裙口袋比工牌还鼓；看上去自称全照手册办事、连暗号都背得滚瓜烂熟。

## [C13] 《十箱纸巾一窝猫》
- 一句话卖点：团嫂喇叭宣布纸巾十箱入库，课代表一复秤，十箱的重量却只有一箱。
- 上架分类：沙雕·团购接龙猫签收 / 3 人 / 入门 / 60 分钟
- 公开背景：三号楼团购群今早炸了：团嫂拿喇叭宣布「纸巾十箱已入库」，可课代表算盘一响、复秤一称，十箱的重量只有一箱。群里立刻分成两派，一派怀疑铲屎官囤十箱想倒卖，一派坚称账本一个字没错。团嫂翻出昨夜录音，背景里分明有猫叫，还夹着她自己那句「等猫回窝再卸货」。账本收货人一栏按着一枚梅花状的猫爪印，旁边歪歪扭扭写着「已签收」——一场关于十箱纸巾的沙雕公案，就这么开了庭。
  - 广场舞·团嫂：拿喇叭管全楼的团购团长，嗓门能盖过广场舞音响；看上去坚称十箱规规矩矩入了库、账本一字没错。

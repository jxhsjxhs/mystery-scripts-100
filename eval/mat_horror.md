## [H01] 《合婚帖》
- 一句话卖点：一张写着活人八字的合婚庚帖，头七前夜在灵堂红烛灭尽时不见了。
- 上架分类：恐怖 / 民俗怪谈 / 2 人 / 入门 / 75 分钟
- 公开背景：民国廿三年，湘西沅水边落了七天冷雨。沈家独子病殁，按旧俗要办一门阴亲。媒婆捧着庚帖挨家讨生辰，说替亡郎配位新妇。头七前夜，灵堂红烛齐齐灭了，供桌上写着新妇八字的庚帖不翼而飞，只余半枚胭脂指印。镇上人都说，是死人自己来相看媳妇——可帖里那姑娘分明还活着，正坐在染坊缝寿衣。红白灯笼一起晃，这桩阴亲，到底还缺了什么？
  - 冥婚·桂姨：走村串寨专办阴亲的媒婆，看上去只想把这门亲事稳稳办完。
  - 冥婚·阿禾：染坊绣娘、八字被写进庚帖的姑娘，看上去只顾低头缝寿衣、自称与婚事无干。

## [H02] 《赶尸·点数》
- 一句话卖点：义庄七具喜神照例子时唱名，铃摇三遍，草席下却多出一口活气。
- 上架分类：恐怖 / 民俗怪谈 / 2 人 / 进阶 / 80 分钟
- 公开背景：湘西辰州，霜降前夜，义庄暂厝着七具待赶回故土的喜神。赶尸匠按老规矩，每宿子时点额朱砂、摇摄魂铃，逐一唱名核数。今夜铃摇了三遍，草席下却多出一个人的呼吸。更夫提灯巡到庄后，见泥地里一行脚印只有进、没有出；尸队最末那具喜神额上的朱砂，是新的。山雾漫进天井，七盏引魂灯忽明忽暗。点数明明该是七，这一夜，到底多出了谁？
  - 赶尸·麻叔：赶尸一行的老师傅，看上去只认点数与行规、半点不容人搅局。
  - 赶尸·老陀：义庄守夜的更夫，看上去只管打更添油、不愿沾赶尸的事。
- 讨论升级：子时点数多出一具、额砂未干鞋底沾青苔，该按行规当场点破、逐出这人，还是借赶尸旧俗放他随队出山？朱砂干湿、脚底泥色、尸牌笔迹该信哪条，这一票怎么投。

## [H03] 《镜中人·反字》
- 一句话卖点：老公寓的落地镜里人影总慢半拍，雷雨夜镜面浮出一行反写的字，像是求救。
- 上架分类：恐怖 / 都市传说 / 3 人 / 进阶 / 90 分钟
- 公开背景：沪上租界一栋老公寓二层，有间梳头间，落地镜是前清遗物。入夏以来，住客都说镜里的人比自己慢半拍：你抬手，它迟一息；你转身，它还在原地望你。今晚雷雨，镜面忽然蒙上一层水汽，浮出一行反写的字，像是求救。老铜匠被请来卸镜，梳头娘姨攥着钥匙不肯开，穷学生却说昨夜亲眼见镜里那人走了出来。电灯一闪，三个人的倒影，好像少了一个。
  - 镜中·菱娘：公寓二房的梳头娘姨、管着梳头间钥匙，看上去守着旧规矩、不肯让人碰那面镜。
  - 镜中·窦四：被请来卸镜的老铜匠，看上去只顾量尺寸拆镜框、不多问闲事。
  - 镜中·文生：借住二房的穷学生，看上去被昨夜那幕吓得夜不能寐。
- 讨论升级：镜面水汽浮出一行「勿卸镜」的反字，是求救还是不叫人碰镜？该信小镜翻出的字、还是量出的框厚与墙纸破口，这一票拆不拆镜怎么投。

## [H04] 《回魂夜·灰上脚印》
- 一句话卖点：回魂夜灵前撒的糠灰上，五更开门印着一双缺角布鞋印，那鞋还穿在活人脚上。
- 上架分类：恐怖 / 民俗怪谈 / 3 人 / 进阶 / 90 分钟
- 公开背景：皖南一户人家，老太爷咽气恰在子时。按老例，头七回魂夜要在灵前撒一层糠灰，关门闭户、全家回避，天亮看灰上有没有脚印，便知亡魂回没回来。游方道士掐指算出回魂在丑时三刻、从东南来。可五更开门，灰上果然印着一双鞋底带缺角的布鞋印，长媳当场哭晕，幼弟却盯着灰发抖——那双缺角鞋，分明还穿在活人脚上。香灰未冷，门闩却是从里头插上的。
  - 回魂·芸娘：操持丧事的长媳，看上去诚心守孝、只盼公公魂魄平安归宅。
  - 回魂·鹤龄：被请来做头的游方道士，看上去只按老书推时辰方位、不管别事。
  - 回魂·阿宝：懂事又胆小的幼弟，看上去被灰上那双鞋印吓得不敢近灵堂。
- 讨论升级：头七灰上一双缺角鞋印，是亡魂踩的还是活人趁空档落的脚？该信道士圈改的时辰、还是信鞋拓与从里插的门闩，验棺枕这一票怎么投。

## [H05] 《凶宅·租约》
- 一句话卖点：老洋房租金低得反常，搬进头一夜墙里三下又三下地敲，雨里忽然回敲了第四下。
- 上架分类：恐怖 / 都市传说 / 3 人 / 进阶 / 90 分钟
- 公开背景：城南一栋三层老洋房，挂了三年吉屋招租，租金低得反常，却没一个住客挨过第七夜。中介登记簿上，退租理由一栏都写着同一句：夜半有人敲墙。新来的女房客不信邪，搬进当晚就听见三下、三下、又三下的敲墙声，节奏和隔壁空了半年的那间一模一样。守灯人每晚来点楼梯口的灯，说这宅子空着比住着更热闹。雨夜里，墙里忽然回敲了第四下——比她数出的，多了一下。
  - 凶宅·灯伯：每晚来点楼梯灯的老守灯人，看上去只管点灯熄灯、劝人夜里别上三楼。
  - 凶宅·佟三：经手三年租约的房产中介，看上去急着把空房租出去、对闹鬼一口否认。
  - 凶宅·苏蔓：新搬进的女房客，看上去不信邪、立志住满七天。
- 讨论升级：三年退租簿都写同一句「夜半有人敲墙」、墙里偏多回一下，该信退租簿还是信空鼓夹墙与多领的夜饭油？这一票破不破墙怎么投。

## [H06] 《深夜电台·倒带》
- 一句话卖点：零点后的《夜航信箱》，磁带转到一半自己倒着走，喇叭里挤出一句像从明晚传回的人声。
- 上架分类：恐怖 / 都市传说 / 4 人 / 硬核 / 100 分钟
- 公开背景：城郊一座快拆的广播楼，零点后只剩《夜航信箱》还亮着。主播念信，导播切带，修带师守着老开盘机。入梅以来每逢周三，总有一通听众来电提前报出次日才发生的事：哪班夜车晚点、哪户半夜哭。今晚磁带转到一半忽然自己倒着走，喇叭里挤出一句压扁的人声，像从明晚传回来。常末分钟打进电话的听众又报一桩：明晚零点，这间直播室会死一个人。灯管嗡嗡响，四人都听见了。
  - 电台·岚姐：《夜航信箱》主播，看上去只想稳住节目安抚听众、不肯认预言是真的。
  - 电台·老韩：值夜导播，看上去只管切带报时、嫌设备老旧老出故障。
  - 电台·屈工：修开盘机的老师傅，看上去埋头修机器、只当倒带是皮带松了。
  - 电台·阿澈：总在末分钟来电的听众，看上去声音怯生生的、只当自己热心报料。
- 讨论升级：周三来电总早一天报出次日的事、磁带自己倒着走，该信「来自明晚」还是信胶带接头与底噪频谱？这一票旧带放不放怎么投。

## [H07] 《医院夜班·三班表》
- 一句话卖点：交班表写着 3 床零时平静，呼叫铃却在一点十七分响过，走廊尽头那盏灯又亮了。
- 上架分类：恐怖 / 心理惊悚 / 4 人 / 硬核 / 100 分钟
- 公开背景：市立医院旧楼三病区，凌晨两点只亮一盏走廊灯。交班表上写着「3 床 夜里零时平静」，可责任护士记得，那张床的呼叫铃在一点十七分响过——而 3 床的老人，病历上明明白白写着零时零七分临床死亡。更邪的是，死亡记录、输液卡、心电图纸三样东西的时间对不上：一个说零时，一个说一点，一个画着一条不该再起伏的线。值夜的医生、护工、实习生，各自都记得自己那一班没出过错。走廊尽头，3 床的呼叫灯，又亮了。
  - 夜班·苓姐：三病区责任护士，看上去照交班表做事、坚称零时后没进过 3 床。
  - 夜班·祁医生：值夜医生，看上去只认自己签字的死亡记录、不容人质疑。
  - 夜班·窦婶：夜班护工，看上去只管送水擦身、说自己不识字看不懂表。
  - 夜班·小乔：轮转实习生，看上去唯唯诺诺、说整晚都在治疗室抄医嘱。
- 讨论升级：3床零时零七分已临床死亡、呼叫铃却在一点十七分响，该信签字的死亡记录还是信四条对不上的时间线？这一票底联上不上报怎么投。

## [H08] 《山村祭祀·签筒》
- 一句话卖点：祭山神的神前拈阄，头一签偏点了外来货郎，鼓声起时四盏松明灯同时矮了半寸。
- 上架分类：恐怖 / 民俗怪谈 / 4 人 / 硬核 / 110 分钟
- 公开背景：黔东南一座封了山口的寨子，秋后要祭山神求来年不塌坡。旧例是神前拈阄，从寨里选一名送福人守山一夜，天亮即归，从没出过事。可今年庙祝捧出的签筒，头一签就点了外来的货郎——寨里几十年没让外姓沾过阄。傩面师连夜赶糊一面新傩面，守灯少女说昨夜见有人往签筒底塞了东西，货郎自己则笑着认了命，说山神挑我，我认。鼓声起，四盏松明灯同时矮了半寸，像被谁按了一下。
  - 山村·盘公：主持祭祀的庙祝，看上去一切只按神意、签筒不许人私看。
  - 山村·岩叔：糊傩面的老匠，看上去只顾赶制祭典面具、不问人事。
  - 山村·阿萤：守祭灯的少女，看上去只管添油守灯、说自己什么都没看见。
  - 山村·罗拐：走山货的外来货郎，看上去被点中后一口认命、反劝众人莫违神意。
- 讨论升级：头一签偏点外姓货郎、签筒底藏着竹夹片与灌铅签枝，该信盘公口中神意还是信祭簿刀痕与按矮的松明灯？这一票傩面开不开怎么投。

## [H09] 《旧照·多出的人》
- 一句话卖点：留真照相馆阁楼翻出一箱民国合影，每隔几年照片里就慢慢多出一个垂手的影子。
- 上架分类：恐怖 / 都市传说 / 2 人 / 入门 / 80 分钟
- 公开背景：旧城拆迁，照相馆「留真」在阁楼翻出一箱民国合影。老板娘说，凡被收进这箱的照片，每隔几年就会多出一个人：原先空着的廊柱边，慢慢立起一个垂手的影子，谁也认不得。修表匠拿来一张自家 1947 年的全家福，指着最末排说，那多出来的人穿的是他父亲下葬时的鞋。可老板娘记得清清楚楚，这箱子是去年才从河滩捞上来的，照片却一年比一年旧。窗外拆楼的闷响一声声，相纸上的影子，好像又往人堆里挤了半步。
  - 旧照·锦姨：留真照相馆老板娘，看上去守着老箱子直叹邪门、劝人别细看。
  - 旧照·闵伯：来查全家福的老修表匠，看上去认定照片闹鬼、想讨个说法。
- 讨论升级：合影每隔几年就多一个垂手影子，该信锦姨说的邪门还是信灯箱下空着的底片与账本那笔补人收银？这一票底片验不验怎么投。

## [H10] 《童谣·数到七》
- 一句话卖点：封了十年的旧幼儿园里，有人把童谣数到七就停，风推着锈秋千，铁链一声一声打拍子。
- 上架分类：恐怖 / 都市传说 / 2 人 / 入门 / 75 分钟
- 公开背景：城郊新村的旧幼儿园要拆，围挡里头还留着一架锈秋千。附近小孩传唱一首没人教过的顺口溜：一数梯，二数梯……数到七，别回头。传得邪乎：谁在秋千上数到七，身后就会多一级本不存在的台阶。代课女先生小时候唱过这歌，如今回来清点旧物；看工地的老更夫说，昨夜分明听见围挡里有小孩数数，数到七就停了，可这园子封了整十年。风推秋千，铁链一声、一声，秋千座底下压着半张泛黄的点名册。
  - 童谣·晚姑：曾在此代课、如今回来清点的女先生，看上去只顾收拾旧教具、顺道看看老园子。
  - 童谣·全叔：看守拆迁工地的老更夫，看上去只管巡夜、把哭声都推给风。
- 讨论升级：秋千上数到七身后就多一级台阶、点名册末行却补了「第七个」，该信晚姑清出的旧册还是信全叔说的风声？这一票册子交不交怎么投。

## [H11] 《电梯·不停的层》
- 一句话卖点：写字老楼的电梯铭牌只到 12，夜班的人却说它偶尔在「13」停一下，门开一条缝。
- 上架分类：恐怖 / 都市传说 / 3 人 / 进阶 / 90 分钟
- 公开背景：一栋写字老楼，电梯铭牌写着 1—12，可夜班的人都说它偶尔会在「13」停一下：门开一条缝，外头是没装修的水泥地，灯也不亮。维修工被叫来查，物业抱着投诉簿，常加班的账房则说昨夜被困在里头，眼看楼层数字从 12 跳回 1，中间「嘟」了一声、多了一下。三人进轿厢试梯，按钮面板背后掉出一枚不该有的继电器，而轿顶检修口，有人新拧过螺丝。数字一格格往上爬，到了 12，果然又「嘟」了一声。
  - 电梯·耿师傅：被叫来查故障的老师傅，看上去只认电路图、把「13 层」当接触不良。
  - 电梯·陆姑娘：夜班物业，看上去抱着投诉簿、盼早点修好别再吓着租户。
  - 电梯·温生：常加班的账房先生，看上去被「多一层」吓得够呛、自称昨夜被困过。
- 讨论升级：铭牌只到12层、电梯偏在「13」停一下，该信耿师傅说的接触不良，还是信后焊的继电器与零点后多走的一度电？这一票继电器拆不拆怎么投。

## [H12] 《封印·井泥》
- 一句话卖点：浙西古村老井栏缠着七道褪红布条，清淤捞匣当夜，最外一道齐齐断了，断口不像风吹。
- 上架分类：恐怖 / 民俗怪谈 / 3 人 / 进阶 / 90 分钟
- 公开背景：浙西古村当心有口老井，井栏缠着七道褪红布条，族谱写「镇物在底，启封必殃」。今年清淤，井底捞上一只朽木匣，匣面朱砂画的符被井泥糊了半边。守祠老人说符一破村里就要出事，石匠却认出那木匣的榫口是自家祖传手法，货郎则半夜想拿走匣里那枚铜环。当夜，井栏七道红布齐齐断了最外一道，断口齐整，不像风吹。井水没涨，可全村灯芯都矮了一截。
  - 封印·槐公：守祠堂、管井栏布条的老人，看上去死守祖训、不许人碰木匣。
  - 封印·阿岩：被请来辨木匣的石匠，看上去只认榫口手艺、当匣子是寻常旧物。
  - 封印·章篓：走村收旧货的货郎，看上去笑嘻嘻惦记那枚铜环、想买去。
- 讨论升级：井栏七道红布齐齐断了最外一道、断口齐整，该信槐公「启封必殃」的祖训，还是信刮开井泥后完整的符文与割痕？这一票木匣开不开怎么投。

## [H13] 《招魂·空椅》

  - 胎梦·窦嫂：贴身乳母，看上去说昨夜摇篮自己晃、把小衣藏起是怕冲撞。
  - 胎梦·涂生：宅里账房，看上去翻产房簿只说账目对不上、怕东家查。
- 讨论升级：婴衣针脚该停在第六根还是照梦锁第七根，三更数到七该记梦兆还是产房簿圈字，这一票当众验不验那件藏起的旧衣。

## [H25] 《还愿·乩笔》
- 一句话卖点：年尾还愿扶乩，乩笔无人自走，沙上先划一个「欠」字，又圈住一个名字。
- 上架分类：恐怖 / 民俗怪谈 / 4 人 / 硬核 / 115 分钟
- 公开背景：山腰「感应庙」有个老例：年前许愿，年尾来还愿扶乩，乩笔在沙盘划字算神明回话。今冬怪在乩笔自个儿动了——沙上先划一个「欠」字，又补个被圈住的名字，可扶乩的四人谁都没使劲。庙祝说这是神来讨愿；香客却认出那名字是她三年前「许了没还」的亡兄；乩手摸笔杆，发现笔头新缠一圈细铁丝；簿吏翻愿簿，那页墨比旁边都新。殿外雪落无声，沙上「欠」字末笔忽然又往回拖了半寸。
  - 还愿·盘公：感应庙庙祝，看上去把乩笔自动说成神明讨愿、催众人快补还愿。
  - 还愿·芮娘：来还愿的香客，看上去认出沙上名字是亡兄、慌着要补做功德。
  - 还愿·篾生：扶乩的年轻乩手，看上去说自己没使劲、只念叨乩笔动得邪门。
  - 还愿·佟九：管愿簿的庙里簿吏，看上去翻簿只说墨色新旧不一、怕年尾盘账露馅。
- 讨论升级：沙上「欠」字该记神明回话还是笔杆细铁丝与磁砂，愿簿新抄页对经卷原页该信哪条，这一票当众对不对原页。

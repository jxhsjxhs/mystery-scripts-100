# 职场厮杀本 · 零剧透评审素材（O01–O25）

> 仅供学生评审 agent 使用。本表已剔除真相/反转/结局/隐藏秘密。
> 严禁打开终稿全文或主持人手册。评语要印在盒面上，读完只想买、猜不出答案。

## [O01] 《末位淘汰：互投之夜》
- 一句话卖点：四个同职级的人关进小会议室，今晚互投出一个走的人，票投给谁，全看谁先绷不住。
- 上架分类：职场博弈 / 4 人 / 进阶 / 90 分钟
- 公开背景：季度末，某事业部只剩最后一个安全名额。HRBP 把四名同职级员工请进小会议室，宣布当晚互投出一名垫底绩效，得票最多者月底走人。桌上四份打分表、一支录音笔，还有一张写着「豁免券」的空白卡。空调开得很足，没人先开口——这张桌子底下压着的不是业绩，是彼此攒了半年的把柄。窗外年会彩排的鼓点一阵紧似一阵，像在替谁倒计时。这一票，到底会落在谁头上？
  - 卷王·赵 P7：组内业绩第一、主动要求主持互投，看上去把「公平」两个字钉得最牢。
  - 老黄牛·钱 P6：工龄最长、从不争辩，看上去早把「走也行」三个字咽了下去。
  - 表哥·孙 P6：做报表出身、消息最灵通，看上去急着把三个人撮成一伙。
  - HRBP·李姐：主持会议、握着规则解释权，看上去只想让流程自己走完。
- 讨论升级：四人被关进小会议室互投一个C绩效，可打分表备注和那张「豁免券」才是真筹码：这局该吵的是按数据淘汰最弱者，还是谁肯先把把柄落字换一句"不投我"。

## [O02] 《晋升答辩：一个坑三个人》
- 一句话卖点：一个晋升名额摆在三个人中间，评委名单被涂改过一格，认领单今晚替谁作数？
- 上架分类：职场博弈 / 3 人 / 硬核 / 100 分钟
- 公开背景：某公司放出唯一一个晋升名额，答辩定在周五下午的玻璃会议室。三名同职级各交了一叠厚材料，评委名单拖到开场前才贴出来，还被人涂改过一格。规则里压着一条少有人细读的附注：分数由评委票、同事互评、贡献声明三项相加，而贡献声明允许认领他人模块，只要对方在认领单上签字。走廊里于是有人低声谈条件：我替你认领，你在我上场时别举手。这唯一一个坑，到底留给谁？
  - 答辩咖·周 P7：材料最厚、最早约了会议室彩排，看上去把「凭实力」念得最响。
  - 陪跑·吴 P7：资历最浅、材料最薄却异常淡定，看上去只是来听一耳朵。
  - 评委秘书·郑敏：排会收材料、管认领单的唯一经手人，看上去只认签字不认人。
- 讨论升级：一个P8名额三个人答辩，规则附注却写着"贡献声明"可认领他人模块、只要对方亲笔签字：这局该吵的是凭材料硬碰硬，还是谁肯先在连号认领单上落那一笔。

## [O03] 《复盘会：责任链拼图》
- 一句话卖点：凌晨串了库，上午就复盘，三人各带一段日志，责任链拼齐那天，签字的是谁？
- 上架分类：职场博弈 / 3 人 / 进阶 / 90 分钟
- 公开背景：凌晨两点，一笔结算串了库；上午十点，复盘会准时开始。白板上贴着一张空白的责任链时间轴，三人各被通知只带自己那段日志来，谁都没见过全貌。群里有人发了句「谁主动认，我记谁一份担当」，随即撤回。空调没开，纸杯泡面味混着打印墨味。时间轴一格一格拼上去，拼完就得有人在责任人栏落笔——那支笔，究竟该谁接？
  - 值班·王工：当晚值守、第一个发现告警，看上去只想让日志替自己说话。
  - 复盘·冯主管：主持复盘、负责拼时间轴，看上去只对着事不对着人。
  - 变更单·陈总监：深夜下过一条口头指令、本人未到会，看上去把话留在了助理送来的单子上。
- 讨论升级：三人各带一段日志来拼责任链时间轴，可谁先亮那段、谁就同时露出"自己在场且动过手"：这局该吵的是把链拼全，还是谁肯先在事故责任人栏签字散会。

## [O04] 《庆功宴：功劳拍卖》
- 一句话卖点：庆功宴上抢一张署名榜，文档、提交记录和表扬信都摆上桌，散席前算谁的？
- 上架分类：职场博弈 / 3 人 / 入门 / 80 分钟
- 公开背景：某项目提前上线，公司包下日料店最里侧的包间办庆功宴，墙上贴着一张空白的功臣署名榜，说散席前填满就报上去评优。三杯清酒下肚，话题从「辛苦了」拐成了「这块到底算谁的」。刺身拼盘刚撤走，有人把一叠文档初稿压上转盘，有人打开笔记本亮出提交记录，还有人摸出一封皱巴巴的客户表扬信——抬头那行名字，三个人谁都没先念出来。散席前，这张榜会写上谁？
  - 需求·褚姐：最早写需求文档的人，看上去认定源头最该占第一行。
  - 代码·卫 P6：主力开发、提交记录最密，看上去只认「谁真做出来」。
  - 客户成功·蒋哥：对接客户、带来表扬信，看上去只想把和气打圆到场。

## [O05] 《竞业协议：同一份模板》
- 一句话卖点：两份竞业协议连错字都一样，谁先举证对方入职更早，谁就少赔一半，先眨眼的是谁？
- 上架分类：职场博弈 / 2 人 / 进阶 / 70 分钟
- 公开背景：隔一条马路的两家公司，前后脚走了两个人。离职第十九天，两人同时收到前司法务函：涉嫌违反竞业协议，各索赔 40 万。调解室里只有一张桌、两份协议扫描件、一支旧签字笔。HR 临走留了句：谁先举证对方入职更早，自己的违约金就减半。窗外两处标识隔着玻璃对着亮，像在等谁先眨眼。可两份协议摊开一比，页码、错字、连装订孔的位置都一样——这纸，到底先替谁作证？
  - 跳槽·沈前：先递辞呈、去了对面那家的中层，看上去只想拉人一起把事扛下来。
  - 竞品·韩 P7：晚一周离职、进了同一栋楼另一层，看上去只肯按证据说话。
- 讨论升级：两人前后脚离职、同时收到索赔函，法务写明"举证对方先入职自己违约金减半"，可两份协议页码错字装订孔全一样：这局该吵的是先咬谁，还是先去验那支旧笔。

## [O06] 《泄密调查：保密金》
- 一句话卖点：指认一名同僚就能换本人免查，可两人指到一处就一并升级，今晚谁先敲门？
- 上架分类：职场博弈 / 3 人 / 硬核 / 90 分钟
- 公开背景：某公司的下一代定价模型被人截图发进了行业群，内审当天封了共享盘，把三名有权限的人请进小黑屋。规则念得很轻：每人单独约谈一次，指认一名同僚可换本人免查；可还补了一句——若两人指认同一人，两份指认一并视为串供，指认的人也升级为重点对象。门上贴着访问日志打印件，纸还热着。三人隔着玻璃对视，谁都没先敲门。这屋子最贵的不是模型，是谁先开口那一下。
  - 内审·杨哥：主持调查、掌管约谈顺序与免查签字，看上去把「配合」二字说得很稳。
  - 共享盘·朱姐：权限管理员、日志经手人，看上去只肯让日志自己开口。
  - 打印·秦工：唯一有彩色打印机权限的人，看上去把那天早走说得最轻松。
- 讨论升级：定价模型截图进了行业群，规则念得很轻——指认一名同僚换本人免查，可两人指同一人就双双算串供：这局最该吵的是谁先开口，还是谁都不信别人会沉默。

## [O07] 《裁员名单：名额置换》
- 一句话卖点：三个待裁格、一个安全格，挪进一个就得挪出一个，改动全留痕，今晚谁进那格？
- 上架分类：职场博弈 / 4 人 / 硬核 / 110 分钟
- 公开背景：周三下午，公司内部知识库短暂浮出一份优化建议名单，四个人名赫然在列，三分钟后页面被撤，截图却已传遍部门小群。HR 没否认，只回了句「名单可申诉，改动会留痕」。当晚四人被叫进同一间会议室，桌上摆着一份可编辑的在线表格：三个待裁格，一个安全格；想把一个名字挪进安全格，就得把另一个人从安全挪去待裁，而系统会把每一次改动的工牌号与时间都记下来。这一格安全，今晚归谁？
  - 名单·尤姐：最早把截图转进小群的人，看上去最先把「一起申诉」喊出口。
  - N+1·许哥：工龄最长、最懂赔偿条款，看上去只低头算那笔账。
  - 举报·何 P6：入职最短、最怕被裁，看上去急着拉人互保谁也别动。
  - 审计·吕姐：被派来监督表格合规的人，看上去只提醒「每次改动都留痕」。
- 讨论升级：知识库闪了三分钟的名单被截图传遍小群，桌上在线表格只有一个安全格、挪进一人就得挪出一人且每笔改动都记工牌号：这局该吵的是动不动表，还是谁在替谁递把柄。

## [O08] 《站队：投名状》
- 一句话卖点：表个态还得附一份对方的料，四只没落款的信封却用着同一批纸，今晚这队该站哪边？
- 上架分类：职场博弈 / 4 人 / 进阶 / 110 分钟
- 公开背景：公司里两位副总同天传出争总裁的消息，中层群一夜之间分成两拨。周一晨会前，四个人各收到一只没有落款的牛皮信封，里面一张卡片：「表个态，附一份对方的料，越实越算自己人」。茶水间的打印机一上午没停，谁都看见四份材料用的是同一批纸、同一个纸盒。而两位副总的司机上午分别来过这层楼，放下的是同款信封，连封口的胶带斜角都一样。这态，今晚该表给谁看？
  - 投名状·施总助：总裁办总助、负责收表态卡，看上去两边都传话、谁也不得罪。
  - 连襟·张副总：分管销售、高调拉人，看上去把「跟我站」拍得最响。
  - 连襟·孔副总：分管产研、低调温和，看上去不逼谁、只等人来聊。
  - 骑墙·曹经理：四位中层里最会左右逢源的一个，看上去两边都敬、只认事理。
- 讨论升级：两位副总同天争总裁，四位中层各收到一只没落款的信封、要"表个态、附一份对方的料"，可料越狠越受信任也越留把柄：这局该吵的是交哪边，还是谁两边都不递。

## [O09] 《空降第一周：述职定价》
- 一句话卖点：空降第一周，四人各填一张不可替代性自评表，门外看板空着四格，这价今晚先定谁？
- 上架分类：职场博弈 / 4 人 / 进阶 / 100 分钟
- 公开背景：周一，新总监空降，没带一个旧部，第一件事是给四位老员工各发一张《不可替代性自评表》：写清「离了我会塌哪块」，再附一句期望的保留条件。周二一对一述职，门外贴着一张空白的定价看板，四个名字后面空着四格，等着填「留、调、边、走」。咖啡机坏了整一周，像在提醒这层楼本来就没打算长待。表交上去，那四格今晚先替谁落笔？
  - 空降·严总监：新官上任、只带一支录音笔，看上去只想先听大家把话讲完。
  - 述职·华 P7：业务最强、开口就要加薪，看上去认定这块离了自己转不动。
  - 老臣·金 P7：工龄八年、最熟历史包袱，看上去把姿态放得最低。
  - 表忠·魏 P6：最年轻、最会来事，看上去把「不要条件」说得最顺。
- 讨论升级：新总监给四位老员工发《不可替代性自评表》要"写清离了我会塌哪块"再报保留价，可定价看板四个格子从填第一笔起就等着填去向：这局该吵的是报高还是报低。

## [O10] 《年终奖：密封报价》
- 一句话卖点：十八万奖金池锁死，三人各写一张密封比例，加起来超一百就全充公，今晚谁先报？
- 上架分类：职场博弈 / 3 人 / 入门 / 70 分钟
- 公开背景：腊月二十八，某小部门年终奖池子锁死在 18 万。HR 发了条新规：三人各在纸条上写一个「我应得的比例」，密封交齐后当场拆——三个比例加起来不超过 100%，按各自报数发；一旦超过 100%，全池冻结、充公归公司，谁也拿不到。群里安静了十分钟，开始有人私聊「你别报太高，咱俩压一压他」。茶水间看板还亮着，上面是三人这一年的加班时长，谁多谁少，一眼就够吵三回合。这三张纸条，今晚怎么个报法？
  - 报价·陶姐：全年加班最多、最早提议按工时算，看上去把「不多要」说得很稳。
  - 看板·姜 HR：发规则、收密封条、管看板的人，看上去只想把流程走完。
  - 结盟·戚 P6：加班最少、最会算账，看上去急着拉人先把第三个数压下去。
- 讨论升级：十八万奖金池锁死，三人各密封写一个"我应得比例"、加起来过100%就全池充公：这局该吵的是压别人还是压自己，还是先问一句这钱到底还在不在。

## [O11] 《360 环评：不匿名的匿名》
- 一句话卖点：弹窗写着匿名互评请放心，满分券差评券却能在截止前互换，这分今晚给谁留着？
- 上架分类：职场博弈 / 4 人 / 进阶 / 100 分钟
- 公开背景：季度环评上线，系统弹窗写着「匿名互评，请放心打分」。四人各领到一张满分券和一张差评券，可自留、可交换、可囤到截止前最后一秒。规则补了一行小字：为保障公正，后台保留「提交时间簇」供抽查。茶水间里已经有人在低声换券：「我给你满分，你别给我差评」。会议室那台路由器这半小时把四个工牌号的登录时间记成了一串连号。这轮分，今晚该怎么落笔？
  - 满分券·谢 P6：最先提议互给满分的人，看上去把「皆大欢喜」喊得最顺。
  - 差评券·邹 P6：攥着差评券迟迟不投，看上去只肯按自己那把尺子落笔。
  - 后台·喻 BP：管环评系统、发券、收导出表，看上去把「绝对」二字保证得很稳。
  - Wi-Fi·柏运维：被叫来保障系统的运维，看上去只管网、不往内容里看一眼。
- 讨论升级：匿名承诺与连号时间簇摆在同一张桌上：这局最该吵的是，换券互保算不算串通、导出表表头备注该不该信、以及要不要联署去质疑那句『绝对匿名』。

## [O12] 《报销造假：连号那顿饭》
- 一句话卖点：同一天同一家餐厅两笔招待，金额都卡着线、发票连着号，今晚谁先说明白？
- 上架分类：职场博弈 / 2 人 / 进阶 / 70 分钟
- 公开背景：月末财务抽查，两笔「客户招待」被挑了出来：同一天、同一家餐厅、金额刚好卡在审批线以下，发票却连着号。二人被请进财务小间，桌上摊着两张报销单、一本纪要模板领用簿。会计临走留了句：「你们俩谁先说明白，另一笔就按已核过掉」。空调外机嗡嗡响，计算器被推到桌面正中。两张单子并排摆着，谁都看得出这顿饭没那么简单——可这第一句，今晚该由谁起头？
  - 连号·水会计：财务侧稽核、手里握着两张发票底联，看上去只肯按制度把话讲完。
  - 纪要·窦助理：其中一笔的经手人、管着纪要模板，看上去把「补个纪要」说得很轻。
- 讨论升级：连号发票、同人领用的纪要编号、早于抽查预勾的『共同责任人』摆在桌上：最该吵的是该信哪条物证、举报还是串供、谁先开口『说明白』。

## [O13] 《PPT 剽窃：最后保存者》

# 搞笑本 · 商业化分析与写作指导（导师）

## 一、本卷商业化定位

目标客群：公司团建、朋友聚会、家庭亲友局、同学会，尤其适合第一次玩本的新手、想破冰的社恐、爱接梗的社牛；2–4 人小局、60–90 分钟、入门为主，随到随开、读完就能玩。情绪基调：轻松、荒诞、无门槛、能笑出声——不吓人、不烧脑、不扎心，主打「读着就乐、开口就破冰」，笑完还带一点熟人之间笨拙的暖。电商/货架分类：喜剧·欢乐·沙雕本、聚会破冰、新手入门、2–4 人本、60–90 分钟、团建娱乐；常挂 #搞笑本 #无门槛 #破冰 #团建 #入门。与另三卷差异化：恐怖卷卖「悬与瘆」、反转卷卖「疑与惊」、职场卷卖「扎心与厮杀」，本卷只卖「破冰、无门槛、能笑出声」——不靠吓、不靠绕、不靠戳痛点，靠锦鲤成精、道具作证、重名登记、隐藏款是老板这类开场就公开的荒诞设定，把人一秒拉进热闹里。组局与定价建议：定价走四卷里最低一档、以走量为主；主推「饭后一局」「团建暖场」「亲友破冰」场景，2 人本做引流款、3–4 人本做主力款，可与另三卷搭「先笑后吓」组合装。系列品牌口径：百局·欢乐品类，统一口径「无门槛、能笑出声、破冰第一局」，25 本共用沙雕语气与货架标签写法，像一个品牌出的系列；盒面只到疑云/荒诞为止，绝不出现真相、反转、谁在恶作剧与结局包袱。

## 三、本卷通用准则（5 条）

1. **沙雕语气**：全卷统一荒诞、轻快、接梗式口吻，短句带笑点，像同一厂牌出的系列；不端着、不煽情过头。
2. **破冰感**：落点永远是「一读就想开口、一开口就破冰」，强调 2–4 人小局、社恐社牛都能玩；别写成需要硬核推理的烧脑本。
3. **字数**：指导表每格 8–25 字；写手成稿每块 220–320 字，盒背只铺场景与疑云，不堆设定、不写解答。
4. **标签**：统一 `#搞笑本 #破冰 #无门槛` + 人数 / 难度 / 时长 / 题材关键词，25 本写法一致，便于货架与电商归类。
5. **品牌语**：守住「百局·欢乐品类／破冰、无门槛、能笑出声」口径；**别写成恐怖、别写成职场**——不出现瘆人氛围，不出现 KPI/HR/厮杀扎心。

## 四、给写手的 5 条硬指令

1. 只读 `commercial/guidance/素材_comedy.md` + 本指导 + 包装规范，**绝不打开 `comedy/搞笑本25套.md` 终稿**；素材表里没有的人物、地点、道具、机制一个都不加。
2. **盒背文案只到疑云/荒诞为止，别抖包袱**：开场公开的荒诞设定（道具成精作证、锦鲤附体、重名登记处、隐藏款是老板）尽管拿来当卖点；但不写「其实／原来／真正的是」、不写真凶、不写谁在恶作剧、不写结局与分支。
3. 逐本对照「严禁剧透点」一列自查，那一列点名的真相、反转、隐藏秘密、结局包袱一个字都别提前泄；角色预告只写公开身份 + 一句「看上去……」的悬念，不写个人目标。
4. 25 块编号 `01`–`25` 连续、剧名与素材表逐字一致；角色预告行数 **== 该本人数（2/3/4）**、角色名逐字照抄；一句话卖点走「荒诞」，不走「悬／疑／瘆／扎心」。
5. 分段落盘防零输出：按包装规范第五节分批写、每批即存盘；全中文，除通用缩写外不夹英文/拼音；只改 `commercial/pack_comedy.md` 一个文件。

# 职场厮杀本 · 商业化分析与写作指导（导师）

## 一、本卷商业化定位

目标客群三类：采购团建的公司行政与 HR、正经历末位淘汰与晋升答辩的职场人、想换口味的老玩家。情绪基调是扎心、代入感、团建后劲，黑色幽默、克制，不写成搞笑卷。电商与货架归入「职场博弈 / 机制对抗 / 现代都市 / 团建社交」，按 2–4 人、70–110 分钟、入门到硬核分档陈列。与另三卷拉开：恐怖卖瘆、反转卖疑、搞笑卖荒诞，本卷卖「这事我上周刚经历过」的代入，和散场后同事对看一眼的沉默；靠规则把人逼出原形，不靠惊吓与段子。组局与定价：2 人本做午休破冰轻量局，3–4 人进阶硬核本做部门团建主局，按人数时长分两档定价，团建批量走套装、老玩家单盒走硬核档。系列品牌口径：「百局·职场厮杀」——没有凶案，只有工位；没有真凶，只有流程。25 本写尽互投、答辩、复盘、庆功、裁员与站队，句句通用职场，人人能对号入座，却认不出具体哪家公司。扎心不说教，散场那点后劲才是回头客。

## 三、本卷通用准则（5 条）

1. 卖点锁定「扎心、代入感、团建后劲」，但**不得出现任何真实公司名、真实人物、可指认的行业事件**；公司一律写成「某事业部 / 部门 / 公司」等通用职场，不给具体企业对号入座。
2. 仅 `KPI / HR / HRBP / PPT / IP / U盘 / BP / HC` 等通用缩写可保留，其余英文与拼音一律不出现，全中文行文；不写外文品牌、外文系统名。
3. 语气黑色幽默、克制、点到即止；不堆段子、不抖包袱、不写成搞笑卷，与搞笑本明显拉开；扎心但不说教，沉默感比笑点更重要。
4. 零剧透红线：只取公开背景里的场景、公开身份、公开矛盾。末位淘汰互投、晋升答辩、裁员名单、PPT 剽窃、360 环评、会议室窃听等开场即公开，不算剧透；隐藏秘密、手法拆解、幕后串通、最后一层反转、结局一律不碰。
5. 全卷句式、标签、口吻统一，像同一品牌出的系列；剧名、角色名、人数、时长、难度逐字以素材表为准，不新增素材表里没有的人物 / 地点 / 道具 / 机制。

## 四、给写手的 5 条硬指令

1. 逐本按本表「开场导语切入点」写主持人开场，把公开场景（互投、答辩、复盘白板、庆功署名榜、裁员表格、表态信封、自评表、密封纸条、环评弹窗、连号发票、撞稿投影、比价标书、转正编制表、内推登记、团建时间线、错抄邮件、同秒双刷、预约表、期权骑缝、调岗志愿、交接清单、军令状、架构图）铺成氛围，落点只到「今晚要查清什么」，不确认任何人的说法。
2. 「角色预告」每本行数严格等于本局人数（2 / 3 / 4），角色名与素材表逐字一致，只写公开身份 + 一句「看上去……」的悬念，不写隐藏秘密、不写个人目标。
3. 逐本对照「严禁剧透点」自查：凡涉及谁动名单 / 谁抄谁 / 幕后串通 / 最后一层反转 / 结局的表述一律删；拿不准就退回素材表——素材表里没有的信息不写。
4. 卖点与盒背只到「疑云」为止，用「到底是谁」「算谁的」「谁先开口」这类悬念收尾，不写「其实 / 原来 / 真正的是」，不拆解物证如何闭合、不点破评分与归属。
5. 每块固定 7 段、约 220–320 字、上架标签 5–7 个（含人数 / 类型 / 难度 / 时长）；难度按入门 / 进阶 / 硬核、时长按 70–110 分钟取自素材表，2 人本做破冰、3–4 人进阶硬核本做团建主局，保持系列感。

# 百局 · 商业化包装规范（8 个 agent 共读）

> 本文件是「4 组 ×（1 导师 + 1 写手）」协作的**唯一契约**。
> 目标：为 100 本盒装本各产一份**可以直接印在盒面、贴到电商详情页、由 DM 当场念出来**的商业化文案。
> 生成器 `scripts/build_box.py` 会把本规范约定的 `commercial/pack_<卷>.md` 自动注入每本的
> `盒面文案.md` / `主持人手册.md` / `本盒完整内容.md`，无需手工合并。

---

## 一、最高红线：零剧透（违反即整卷作废）

这批文案是**给还没玩的顾客/玩家看的**。任何一块里**绝对不得出现**：

- 真相、真凶 / 幕后执行者、动机全貌；
- 反转的内容（"其实……""原来……""真正的是……"）；
- 任何角色的**隐藏秘密**、以及由秘密直接推出的身份；
- 核心诡计的**解法 / 手法拆解 / 物证如何闭合**；
- 结局、分支结局、投票结果、谁赢。

**可以写**：场景、时代、人物公开身份、公开矛盾、疑云、氛围、"到底是谁干的"这类悬念、
玩法类型（如"物证搜证""时间线比对""身份辩认"）、人数 / 时长 / 难度 / 客群 / 上架标签。

判定口径：把文案给一个没玩过的人看，他读完后应当**只想买、但猜不出答案**。

### 防剧透的结构性保障（务必遵守）
- **导师**读终稿全文（允许知道真相，才能列出"严禁泄露点"）。
- **写手只读 `commercial/guidance/素材_<卷>.md`**（这是刻意去掉了秘密/反转/真相的投影）
  + 导师的 `guide_<卷>.md` + 本规范。**写手不要打开 `<卷>/*.md` 终稿全文**，
  因为里面含真相，读了极易写漏。素材表里没有的信息，就不要写。

## 三、写手输出：`pack_<卷>.md` 的块格式

- 文件内**恰好 25 个块**，编号 `01`–`25` 连续、不重不漏；顺序按编号升序。
- 每块以 `## [H01] 《合婚帖》` 开头（方括号里是编号，书名号里是**与素材表完全一致**的剧名）。
- 块正文固定 7 段，标题一字不差；每块约 **220–320 字**。
- 文件开头可写一行 `# 恐怖本 · 商业化包装文案` 之类总标题，不影响解析。

### 块模板（格式示例；人名/身份一律以素材表为准）

```
## [H01] 《合婚帖》
- 一句话卖点：一张写着活人八字的合婚帖，在头七前夜不见了。
- 上架分类：恐怖 / 民俗怪谈 / 2 人 / 入门 / 75 分钟

### 盒背文案
（100–150 字。氛围向，铺场景 + 抛出公开疑云，**只到"疑云"为止**，绝不写出答案。）

### 卖点
1. （人数/时长/难度/组局便利）
2. （题材/氛围/美术/沉浸亮点）
3. （玩法类型：物证搜证 / 时间线比对 / 身份辩认 …，只写类型不写解法）

### 开场导语（DM 宣读）
（80–130 字。第二人称或场景白描，把玩家拉进场景、点出本局要查什么，不剧透。）

### 角色预告
- 角色名：一句公开身份 + 一句"看上去……"的悬念，不泄露秘密。
- （每个角色一行，行数必须等于本局人数；角色名与素材表完全一致）

### 上架标签
#2人本 #恐怖 #民俗怪谈 #入门 #75分钟
```

### 各段硬性要求
1. **一句话卖点**：25–40 字，一个钩子，不剧透；四卷风格要拉开（恐怖=悬/瘆、反转=疑、搞笑=荒诞、职场=扎心）。
2. **上架分类**：`题材类型 / 人数 / 难度 / 时长`，取自素材表。
3. **盒背文案**：把素材表里的「背景」改写成面向顾客的氛围文案；可保留人物/地点/时间/公开矛盾，**删掉任何指向解答的句子**。
4. **卖点**：3 条，每条 15–35 字；第 3 条写玩法类型，**不得出现诡计的具体做法**。
5. **开场导语**：DM 开场直接念；用"你"或"你们"，落到"今晚要查清什么"，不确认任何人的说法。
6. **角色预告**：行数 = 本局人数（2/3/4），角色名必须与素材表**逐字一致**；只写公开身份 + 表面主张，不写隐藏秘密、不写个人目标。
7. **上架标签**：5–7 个 `#` 标签，含人数 / 类型 / 难度 / 时长 / 题材关键词。

### 全卷风格一致性
- 同卷 25 块的句式、标签写法、卖点条数保持一致，像同一个品牌出的系列。
- 四卷之间语气要明显不同；不要 100 本读起来像一个模板套出来的。
- **禁止**把素材表里没有的人物、地点、道具、机制写进文案。
- 全中文；`KPI / HR / PPT / IP / U盘 / KPI` 等职场通用缩写可保留，其余英文/拼音不要出现。

## 四、导师输出：`guide_<卷>.md` 的格式

```
# 恐怖本 · 商业化分析与写作指导（导师）
## 一、本卷商业化定位
（目标客群、情绪基调、货架/电商分类、与另三卷的差异化、组局与定价建议、系列品牌口径）
## 二、逐本指导表（25 行，编号 01–25 全）
| 编号 | 剧名 | 卖点方向 | 情绪钩子 | 目标客群 | 开场导语切入点 | 严禁剧透点 |
| H01 | 合婚帖 | … | … | … | … | 不得写"庚帖是谁调的包" |
…
## 三、本卷通用准则（5 条）
## 四、给写手的 5 条硬指令
## 五、验收清单（写手自查用）
```

- 「严禁剧透点」一列是导师的核心价值：**导师读过全文，必须把每本最容易被写漏的真相点名写出来**，
  让不看全文的写手也能避开。
- 导师**不写**成品文案，只做分析、定位、逐本指导与验收标准。
- 逐本指导表必须 25 行齐全，编号与剧名和素材表一致。

## 五、写作方式（防"一次输出过多导致空文件"）

历史教训：单个 agent 一次性写 25 套长文多次 `failed before it finished` 零输出。
因此**必须分 3 段落盘**：

1. `write` 写文件头 + 编号 `01`–`09` 的块；
2. `edit`（或再次写入追加）补 `10`–`18`；
3. `edit` 补 `19`–`25`。

每段写完即已落盘，即使中途被打断也不至于全丢。导师的 25 行指导表同理可分 2 段写。

## 六、通用纪律

- **只改自己那一个产物文件**；不碰 `drafts/`、`各卷终稿 *.md`、`scripts/`、`其它 pack_*.md`、
  `README.md`、另一人的产物。
- 不建 todo、不派子 agent、不运行 `build_box.py`、不做 git 操作。
- 完成后用 `send_message` 向 captain 报告：产物路径、覆盖编号数、自查结论（块数 / 行数 / 是否零剧透）。
- 自查要点：25 块齐全且编号连续、剧名与素材表一致、角色预告行数 == 人数、无真相/反转/秘密字样、全中文。

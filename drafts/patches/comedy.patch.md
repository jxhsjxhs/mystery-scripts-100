## [C01] 背景
公司年会搞「阳光抽奖」：全员实名投券，特等奖写「与老板共进私人定制一日游」。开奖前一分钟，行政发现奖箱凭空多出一张纯金烫边、只画胖锦鲤的怪券；开奖瞬间大屏卡成表情包，全公司手机同时收到同一条匿名短信：「别抽了，中特等奖的人会被老板认领」。更离谱的是，老板此刻正缩在后台道具间，坚决否认设过奖，坚称是「锦鲤先动的手」。全场只剩两个被锁会场的人：一个非要查清奖箱、一个只想把老板领走下班。

## [C02] 背景
「旺德福砂锅」小店某天炸了锅：后台显示同一单被连点 27 次「一星差评」又连点 27 次「五星好评」，评语清一色「太咸」「太淡」「咸淡刚刚好」循环刷屏，系统把店标判成「薛定谔的口味」并冻结提现。更邪门的是，骑手取餐箱里多出一张小票，背面写「别查了，这单是我自己跟自己打起来的」。老板关门，把在场的三个人锁进堂食区：不盘清这 27 轮咸淡公案，谁也不许走，包括那只被误登记成「本店口味总监」的橘猫。

## [C03] 背景
城南公园相亲角：同一张「优质男嘉宾」资料卡，一上午被四位家长同时认领，照片是同一人，署名却写成「本人 / 本人母亲 / 本人小姨 / 本人本人」四款，爱好栏被涂改成「爱静 / 爱闹 / 爱静闹结合 / 爱被安排」。凉亭老式打卡钟每逢整点「咔」地吐出小票：「本时段到场人数：1，登记人次：4」。红娘摊主一拍桌：不把「到底来了几位、谁才是真身」盘明白，谁都别摘胸花。四位「家长」面面相觑，其中一位正是被安排来相亲的本人。

## [C04] 背景
「和风雅苑 3 栋业主群」立新规：今晚 20:00–21:00 为「静音实验」，发「收到」罚充十元公共电费。整点一到，群里「收到」刷了 99 条，系统标成「由 3 栋 502 转发」，可 502 业主坚称手机整晚扣在物业前台充电。物业把四位当事人请到活动室，桌上摆着旧路由器、群聊截图，以及一张涂改的《静音实验值日表》。不盘清「99 个收到谁发的」，谁也拿不回暂扣手机——包括那台被拉进群、昵称「3栋路由器」的设备。

## [C05] 背景
「铲屎官」出差前留了罐金枪鱼罐头，贴《临朝托管诏》：三只宠物共管、罐头「待最有德者启」。当晚罐头没开，诏书被啃出三个牙印、旁多一行猫爪蘸印泥踩的「本喵弃权」，阳台监控拍到 23:00 整三个毛影同时扑向罐头又同时急刹，整齐得像排练。出差人远程把客厅封成「临时朝堂」，让三位「当事人」盘清楚：谁（或谁的东西）动了罐头、谁替谁背锅。注意——本朝只审宠物不审人，三位玩家代主子应诉，全程用主子口气说话。

## [C06] 背景
剧组拍古装宅斗大结局，道具间深夜「闹道具」：本该在第 3 场摔碎的青瓷茶盏非但没碎，还滚到监视器前，盏底用茶渍显出「别摔我啊」；场记板「第 3 场 / 摔盏」被改成「第 3 场 / 盏自辩」，清单背面多一行小字：「今夜在场能说话的，只有不会说话的那几件」。导演锁了道具间，让三位「当事人」盘清楚：谁动了茶盏、谁改了场记板、为何全组觉得茶盏「叹了口气」。三位玩家各扮一件道具，不许说「我是人」，只以物件视角作证。

## [C07] 背景
「鸿运科技」晨会转发锦鲤迎周报，行政群发一张胖锦鲤图。一上午全公司 36 人全转、人人领到顺遂奖品，唯独工位靠打印机的那位连转 9 次、9 次都弹「转发失败·运势回弹」，还把打印机卡纸、咖啡机溢杯、增氧泵停摆全揽了。锦鲤图文件属性藏着一句备注：「本鲤只渡不缺顺的人」。行政锁了茶水间，让两位当事人盘清楚：是锦鲤偏心，还是「衰」被人安排得明白。一个证「玄学有效」、一个证「玄学没效」，可每条物证都在帮对方说话。

## [C08] 背景
「不翻不散」直播间卖「全自动静音鼓掌机」，主播喊完「上链接」同一秒，999+ 条弹幕齐变「已鼓掌」，鼓掌机样品「啪」地合上、夹住主播袖口，背景音飘出「感谢家人们，本场由我代播」。后台更离谱：本场「成交 0 单、鼓掌 999 次、在线人数 1」，那 1 个 IP 登记在样品机名下。平台封直播间作「复盘室」，四人盘清楚：链接谁上的、弹幕谁刷的、「代播」谁配的音。复盘期间不许说「卡了」，一说罚重念口播稿。

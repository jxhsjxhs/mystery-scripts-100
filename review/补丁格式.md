# 修订补丁格式规范（4 位写手必读）

每位写手**只产出一个补丁文件**：`drafts/patches/<卷>.patch.md`。
补丁里**只写「需要改动的字段」的新内容**；未出现在补丁里的字段与剧本正文，由 captain 的 `scripts/apply_patches.py` 原样保留。这样你不必重发整本剧本（输出太大易失败），也能真正「按总审核意见修订」。

## 一、补丁块格式

每个改动 = 一个二级标题 + 新内容，块间空一行：

```
## [T09] 题材
叙诡·腕带身份调换

## [T09] 背景
城郊康复院三楼只住着一位「失忆病人」和一名白班护工……（100–200 字，一段）

## [T11] 背景
老报馆后巷出了命案……（一段）
```

- `编号`：必须与初稿一致（如 `T09`、`C03`、`O12`、`H07`）。
- `字段名`：只能取下列之一 ——
  `题材`　`人数`　`时长`　`难度`　`背景`　`角色`　`核心诡计`　`关键线索`　`流程`　`反转点`　`真相`　`主持人`
- 同一个编号可以有多个字段块（例如既改 `题材` 又改 `背景`）。
- 标题后**不要**写解释文字；标题里字段名后可加括号备注（如 `## [T09] 背景（压缩）`），脚本会自动识别字段名。
- 另支持特殊字段 **`替换`**：用于「只把某套正文里几个词换掉」的小改动，避免整段重发。正文每行写一条 `旧串 => 新串`，脚本对该套整块做**字面替换**，按你写的行顺序执行，所以**越具体/越长的放最前**（例：先 `别cue我 => 别点我` 再 `cue => 点名`）。例：

```
## [C04] 替换
社恐·甄别cue => 社恐·甄别点
别cue我 => 别点我
被 cue => 被点名
WiFi => 无线网络
wifi => 无线网络
cue => 点名
```

`替换` 可与 `题材`/`背景` 等块并存于同一编号（例如 C04 既有 `题材`、`背景`，又有 `替换`）。

## 二、各字段怎么写

| 字段 | 写法 | 说明 |
|---|---|---|
| `题材` | 只写新标签文字，**不要**写 `- 题材：` 前缀 | 例：`叙诡·双生身份互换`；照抄《总审核意见书》2.2 给你的 25 个标签，逐字照抄 |
| `背景` | 100–200 字的一段新背景 | **逐字照抄**《总审核意见书》2.1 给你的改写版，勿改写、勿删伏笔 |
| `核心诡计` | 一段新全文 | 仅当意见书要求改此字段时写 |
| `反转点` | 一段新全文 | 同上 |
| `真相` | 一段新全文 | 对应 `### 真相与结局` 段 |
| `关键线索` | 编号列表 `1. 2. 3.`（≥3 条） | 保持编号物证格式 |
| `流程` | `- 第一幕：…` / `- 第二幕：…` / `- 第三幕：…` | 三幕齐全 |
| `主持人` | 2–3 条 `- …` | 对应 `### 主持人提示（DM Notes）` |
| `角色` | 每角色一行 `- **名**：…。表面立场：…。隐藏秘密：…。个人目标：…。` | 行数=人数；必须用**全角冒号** `**：` |
| `人数` / `时长` / `难度` | 只写新值 | 一般不用改；**不得改变人数**（机器校验已锁定） |

## 三、红线

- **不要改编号、人数、角色名、线索条数、9 字段结构**——这些已通过机器校验，终稿还会再校验。
- 不要把整本剧本、整段解释、Markdown 表格写进补丁。
- 题材标签必须按母题细化（T/C/O 三卷各 25 个，照抄意见书 2.2）；horror 卷题材本已 25 种互异，通常不用改，除非意见书点名。
- 意见书第三节「分卷可执行修改清单」里，凡是给了**替换文本**的，逐字用上；凡是让你「自行润色」的，你按上文格式写出该字段新全文。
- 全中文。补丁文件开头可写一行 `# <卷名> 修订补丁（写手：<人设>）`。

## 四、交付

写完后用 `send_message` 向 captain 报告：补丁路径、共改了几个编号、几个字段块、是否覆盖了意见书里本卷**全部**必修项（23 段背景中的本卷部分、75 标签中的本卷部分、第三节本卷全部编号级意见）。
